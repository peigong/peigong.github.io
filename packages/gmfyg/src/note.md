# 讲解提纲

## 刘恒甫作品

### 中华福树

- 材质为不锈钢镜面结构
- 代表了生命之树、文化之树、和平之树，是“人类命运共同体”的美好诠释。

### 丝路祥音

- 凭借不同色彩线条的组合，将“丝绸之路”诠释得极尽完美又富有诗意。

## 千里江山图

- 《千里江山图》是中国十大传世名画之一。
- 北宋王希孟创作的绢本设色画，现收藏于北京故宫博物院。
- 《千里江山图》用一幅整绢画成，无作者款印，有清弘历（乾隆）题诗，后隔水有宋朝蔡京的跋一，尾纸有元朝李溥光的题一。
- 政和三年闰四月八日赐。希孟，年十八岁，昔在画学为生徒。召入禁中文书库，数以画献，未甚工。上知其性可教，遂诲谕之，亲授其法。不逾半岁，乃以此图进。上嘉之，因以赐臣京，谓天下事在作之而已。 
- 画学是宋徽宗于崇宁三年（1104 年）设立的宫廷绘画教育机构，后归属翰林院图画局。
- 青绿山水，是用矿物质的石青、石绿上色。
- 研究指出，《千里江山图》的主要取景地是庐山和鄱阳湖。
- 元代书法家溥光：“该画‘予自志学之岁，获睹此卷，迄今已近百过。其功夫巧密处，心目尚有不能周遍者，所谓一回拈出一回新也。又其设色鲜明，布置宏远，使王晋卿、赵千里见之亦当短气，在古今丹青小景中，自可独步千载，殆众星之孤月耳。具眼知音之士必以予言为不妄云’。”
- 清末被溥仪从皇宫带出宫，搁置在长春的小白楼里，直到1945年日本投降，满洲国灭亡，长春小白楼的文物被哄抢一通，这幅千里江山图流落在民间；在解放初期画卷出现在琉璃厂被爱国人士商人靳伯声收藏，这个爱国人士把这幅藏品捐给了国家；1953年千里江山图正式入藏北京故宫博物院传承至今。

- 彩陶是指在打磨光滑的橙红色陶坯上，以天然的矿物质颜料进行描绘，用赭石和氧化锰作呈色元素，然后入窑烧制。
- 掏膛工艺是薄胎玉器中最重要的环节，是待器身、器盖的外型确定之后，才开始打钻掏膛，并逐渐掏空，其技术要求是膛壁厚薄均匀。
- 夹纻工艺
- 漆线雕用陈年砖粉和大漆、熟桐油等原料调和，经反复捶打成为柔软而又富于韧性的泥团，俗称“漆线土”，再由手工搓成“漆线”，然后在涂有底漆的坯体上用“漆线”盘、结、绕、堆，塑造浮凸的图形。
- 绒绣，又称绒线绣，是一种在特制网眼麻布上用彩色羊毛绒线绣制图案的刺绣工艺，成品具有毛绒质感。

- 德化瓷
- 耀州瓷，是宋代的青瓷代表，民窑的一种，工艺非常有特点，一是纹样属于通体雕刻，胎面形成凹凸变化，纹饰有深浅变化，是北方青瓷的代表
- 龙泉有章生一、章生二兄弟俩擅长制瓷，各有千秋。哥窑瓷器的特点：黑胎厚釉，不同规律的纹片。弟窑特点：白胎厚釉、其中以粉青、梅子青为贵。
- 北宋徽宗时期，官府在今河南省禹州市区东北部设置官窑，为皇宫烧制贡瓷。因窑址邻近古代春秋战国的钧台，故名为“钧台窑”，简称“钧窑”，所产瓷器即名“钧瓷”。
- 钧瓷在烧制中会出现窑变现象，因釉料当中有铜，经火焙烧氧化还原，形成千变万化的紫红釉色。

- 青瓷色调的产生，是因为胎釉中含有一定数量的氧化铁，并在高温火焰中还原烧制而成。唐朝的越窑和宋朝的汝窑、官窑、耀州窑、龙泉窑等，都属于青瓷系统。
- 釉下彩于胎体绘制后高温一次烧成，代表品种有青花、釉里红。
- 釉上彩在烧成瓷胎上二次低温焙烧，典型如斗彩、五彩、粉彩等。
- 釉上彩色与釉下彩色交错重叠从而产生一种争奇斗艳的效果，在古代我们取其“斗”字，叫做斗彩。

- 钦州坭兴陶，简称坭兴陶，以广西钦州市钦江东西两岸特有紫红陶土为原料

- 巴林石产于内蒙古赤峰巴林右旗，巴林石与福建省的寿山石、浙江省的青田石和昌化石齐名，统称为中国“四大名石”

### 四大国宝

- 由国库秘藏的四块翡翠原石制作，他们原本是一整块翡翠原石，重达一千多公斤。
- 1982年由国务院交由轻工业部，又交由北京玉器厂，作品由40多位技艺精湛的大师和数十名专家学者组成的顾问团队共同参与设计制作，原计划在86年完成，所以被誉为86工程，但最终由于设计就用了3年多的时间，共历时八年才最终完成，它们也是新中国玉雕史上唯一一项国家工程。
