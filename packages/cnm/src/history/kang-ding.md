# 亢鼎

亢鼎‌是一件西周早期的青铜器，现藏于‌上海博物馆‌，其铭文记录了西周时期一次用贝币购买玉器的真实交易 。‌‌

## 这件鼎记录了什么交易

- ‌交易主体‌：铭文记载“公太保”向一位名叫“麐亚”的人购买玉器 。
- ‌公太保‌：即西周初年的重臣召公奭 。
- ‌亢‌：是太保手下的官吏，负责经办此次交易 。‌‌‌
‌- 交易内容‌：太保用‌五十朋贝‌购买了“大琮”（一种玉质礼器）。
    - 除了支付贝币，太保还赠送了香酒（鬯）和牛作为礼节 。
    - 交易完成后，麐亚还赏赐给经办人亢青铜 。‌‌‌
- ‌历史意义‌：这是金文中较早明确记录用贝作为货币进行交易的案例，证明西周早期贝币已用于大宗商品买卖 。‌‌‌

## 器物现在收藏在哪里

- ‌收藏单位‌：亢鼎目前收藏于‌上海博物馆‌。
- ‌入藏时间‌：上海博物馆于‌1998年‌从香港征集入藏 。
- ‌器物年代‌：属于‌西周早期‌，大致在成王至康王时期 。‌‌

## 铭文为什么这么重要

- ‌经济史料价值‌：铭文完整记录了玉器买卖的全过程，包括货值（五十朋）、支付方式及附加礼节，为研究西周商品经济提供了直接文字证据 。
- ‌礼制研究价值‌：交易过程中伴随的馈赠酒、牲畜以及事后酬赠铜料的往来，反映了周代贵族交往的礼仪习惯 。
‌- 断代参考价值‌：铭文中出现的“公太保”（召公奭）等人物，为器物断代提供了明确的纪年人事佐证 。‌‌
