# 布币形制的历史沿革

布币是先秦中原“铲形钱”的总称，核心脉络是：青铜农具钱/镈 → 原始布 → 空首布 → 平首布 → 秦圜钱取代。整体趋势是越铸越小、越轻、越标准化，铭文从吉语/干支走向地名+币值。

## 一、源头：钱、镈与“原始布”

- 文献依据：《诗经·周颂·臣工》“庤乃钱镈”，《说文》“钱，铫也，古田器”“镈，锄也”。钱近似锹/铲，镈近似锄，“布”一般认为是“镈”的同音假借。
- 商周黄河流域农业区用青铜铲、锄作交换媒介；完整钱镈约通长160、宽100毫米、重约200克，太大不便流通。
- 西周出现“半镈”（约通长90、宽55、重112克），再演进为原始空首布（通长100多、足宽70多、重约110克），实质是减重、把装柄銎(qióng)缩短到币身上部、开始加简单符号（上、山、六等）。
- 这一阶段仍带农具痕迹：厚、有銎、可装柄；但已不完全当农具用，算“金属铸币雏形”。

## 二、空首布：保留装柄銎的春秋主币

东周空首布首部中空（銎），像缩小铲；按肩、足分三型，主要行于周王畿、晋/韩魏、郑卫宋一带。

1. 平肩弧足空首布
   - 春秋中期周王室先铸，后行王畿；平肩、弧裆、弧足，首部空銎（方或六棱），面背多三竖线，有郭。
   - 分特大型→小型：特大型通长140–150、肩宽60–70、足宽70–80毫米、重50–80克；小型通长63–81、肩宽35–39、足宽37–43毫米、重约15克。
   - 铭文最丰富，单字为主：干支、数字、方位、天干、祭祀名物、吉语、少数地名；“釿”“市南小化”等出现，说明由宗教/行政符号转向经贸记名。
2. 斜肩弧足空首布
   - 周王畿及晋之韩魏系；斜肩，面背两侧各两斜线。
   - 大者通长78–88、肩宽约43、足宽约49毫米、重22–32克；另有小等，整体比同期平肩中型轻。
3. 耸肩尖足空首布
   - 晋国/后继赵系特征强；耸肩、尖足，常面背三竖纹，部分无文，部分有“中一”类标记。山西侯马铸铜遗址材料可证晋地铸造。
   - 体形从大减重到小：大型可30–50克级，晚期更小，过渡到战国平首尖足。

空首布总规律：大型早、重型早；小型晚、轻型晚；铭文由无文/符号→单字→地名/币值。

## 三、平首布：战国主流，彻底脱离农具

战国把空銎去掉，首部改扁平实片，整体成薄铜铲；分肩、裆、足更细，便于批量铸、成串带。赵魏韩周及燕部分地铸，秦晚期以圜钱为主、楚有独立布形。

1. 尖足布（赵系为主）

- 耸肩、方裆、尖足；由耸肩尖足空首布蜕出。大布如“甘丹（邯郸）”“晋阳”“大阴”，通长80+毫米、重10–12克级；小布如“离石”“武安”“兹氏”，通长45–55、足宽23–28、重5–6克。
- 面铸城名，背常数字；大布偏高值，小布日常零售。后期尖足磨损/折断多，部分演类方足、类圆足。

2. 方足布（战国最普及）

- 平/方肩、方裆、方足；赵韩魏燕均铸，小布为主。通长多39–48、足宽24–27毫米，重约4.8–13.5克因型而异。
- 铭文几乎全地名：“安阳”“平阳”“宅阳”“皮氏”“戈邑”“梁邑”等；燕方足常束腰深、背左/右类作坊标记。
- 优点是正方面不易伤手、叠放省空间，战国中晚取代尖足成为北方主流通。

3. 桥足/釿(jīn)布（魏系纪重）

- 圆肩或平肩、桥形弧裆、方足；称“釿布”因面文带“釿”。代表“安邑二釿/一釿/半釿”“梁重釿百当寽”“梁正尚百当寽”等。
- 分二釿、一釿、半釿三等：二釿最重（安邑二釿通长可65毫米级），一釿次之，半釿轻小；以“釿”为重量/价值单位，是战国最早系统化子母相权之一。
- 另有“寽”制大梁布（如“梁正尚金当寽”“梁半尚二金当寽”），偏魏都贸易与高值支付。

4. 锐角布（韩系异形）

- 平首顶端两角外突如小尖耳，方/弧裆；分大、小两等。存世少于方足，主要韩地及邻近。

5. 圆足布与三孔布（赵系晚型）

- 圆首、圆肩、圆裆、圆足；面地名（“晋阳”“兹氏”“离石”“大阴”），背常两斜线。受圜钱圆化审美影响，赵晚期。
- 三孔布：圆足基础上首+双足各一圆孔，面地名、背记重“两”或“十二朱”；大者背“两”、小者“十二朱”，兼地名+铢两，极稀，属先秦纪重纪地高峰。

6. 长布、异形、楚燕尾

- 长布如“长布黄千”类观念可放到新莽再说；战国北方另有小异形布。
- 楚布独立：狭长束腰、两端外撇似燕尾，面“比埒/四比埒当釿”等，与小蚁鼻钱形成兑换，不纳入三晋平首主类。

## 四、减重与形制演化的内在逻辑

- 农具→货币：去掉实用铲深銎，先留空首象征，再改实首薄片。
- 大型→小型：原始布百克级→空首特大型50–80克→空首小型约15克→平首尖/方小布4–12克。
- 尖→方→圆：尖足利但易折，方足规整，圆足/三孔更便穿系；同时肩从耸/平转向圆，整体“去棱角化”。
- 无文→地名→地名+币值：空首单符号，平首大量城名，魏用“釿/寽”、赵三孔用“两/朱”，为秦铢两制铺路。

## 五、秦统一与布币退场

- 战国秦用圜钱/半两体系；惠文王初行钱后，秦地不以布币为主。前221统一“半两”方孔圆钱，北方布、齐燕刀、楚贝形均被整合或废止。
- 秦简《金布律》“钱十一当一布”的“布”指布帛实物，不是铲形布币；别把二者混同。
- 汉承半两/五铢，布形不再流通；新莽复古铸“小布一百…大布黄千”“货布”，纯法古象征，不属于春秋战国实用布币沿革。
