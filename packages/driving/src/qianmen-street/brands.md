# 前门大街的老字号

## 一、正餐与小吃：前门最出片的老字号

### 全聚德（前门店）

- 地址：前门大街30号，起源/老店性质。
- 历史：1864年（同治三年）河北人杨全仁盘下“德聚全”干果铺，反字成“全聚德”，重金请清宫挂炉烤鸭师傅，用果木明炉。
- 看点：店内保留1901年建的老门面墙，“全聚德/老炉铺/鸡鸭店”砖雕匾额；可看“老铺”复原场景。
- 吃啥：挂炉烤鸭（皮脆肉嫩，配荷叶饼甜面酱）、盛世牡丹鸭、火燎鸭心、芥末鸭掌；挂炉烤鸭技艺为国家级非遗。
- 时段：一般11:00–14:30、16:30–21:00，客流大时调整。

### 都一处烧麦馆

- 地址：前门大街38号。
- 历史：1738年山西王氏开“王记酒铺”；1752年除夕乾隆微服回宫唯此亮灯，赐“都一处”蝠头匾。
- 看点：烧麦皮讲究24褶，形似石榴；烧麦制作技艺2008年入第二批国家级非遗。
- 吃啥：三鲜（虾/肉/海参）、猪肉、牛肉、素馅；配乾隆白菜、传统马莲肉，二层有山东炒菜。
- 时段：约9:30–21:00。

### 鲜鱼口一带（小吃集中，归前门片区）

- 天兴居炒肝：鲜鱼口内，前身会仙居1862年，现号1933年；炒肝芡汁、肝肠软烂，配猪肉大葱包子，东城区级非遗。
- 壹条龙：清真，前身南恒顺1785年，民国改“壹条龙”；铜锅涮羊肉、传统清真菜。
- 爆肚冯等鲜鱼口/大栅栏周边摊店：爆肚配麻酱，属于老北京小吃而非单一老号，挑本地人排队的更稳。

### 东来顺（前门大街店）

- 1903年创号，前门店做铜锅清汤涮肉，手切羊肉、麻酱、糖蒜；属清真涮肉老字号，和全聚德、都一处不重样。

### 月盛斋

- 前门有店；1775年（乾隆四十年）起家，清真酱烧牛羊肉，吸收宫廷酱肉与药食同源思路，酱羊肉、烧羊肉、酱牛肉可抽真空带走；酱烧技艺为国家级非遗。

### 天福号

- 前门大街19号；1738年创号，招牌酱肘子“肥而不腻、瘦而不柴”，酱肉制作技艺国家级非遗，适合买礼盒。

## 二、茶与糖点：带得走的老北京

### 张一元（前门大街86号）

- 1900年创“张玉元”，1908年改张一元，取“一元复始”；茉莉花茶拼配是强项，汤清味浓。茉莉花茶制作技艺2008年入非遗。 买高末、龙毫、茉莉香毫作伴手礼都行。

### 吴裕泰（前门大街42号）

- 1887年创号，1955年公私合营后改茶庄，2005年成立股份公司；茉莉花茶九道工艺、2011年入第三批国家级非遗。 前门店除茶叶，还有茉莉/抹茶冰淇淋、茶饼干，年轻人排队多。

### 稻香村（前门大街设店）

- 南味糕点体系，点心匣子、元宵、月饼、京八件；送长辈比散装果脯稳妥。六必居前门有售点：1530年起家的酱菜老号，麻仁金丝、八宝菜、甜酱瓜适合配粥带回家。义利若在前门周边碰到：1895年系老牌，果子面包、巧克力、糖果是北京童年零食向。

## 三、药与养生产业（多在大栅栏）

### 同仁堂

- 1669年（康熙八年）乐显扬创号，后由子乐凤鸣在前门外大栅栏设铺；1723年起供御药。堂训“炮制虽繁必不敢省人工，品味虽贵必不敢减物力”。
- 买啥：牛黄清心、乌鸡白凤、大活络丹、安宫牛黄、参茸；大栅栏老铺看老药柜、问诊所更有“老号”感。 前门西打磨厂、北京坊另有同仁堂健康/智慧体验点，偏零售和养生，不等同老药铺。

广誉远/益德成等在前门大街有国药或闻药小店：广誉远做龟龄集、定坤丹，益德成做鼻烟闻药；属“前门片区老字号”而非传统前门餐饮，顺路可看。

## 四、穿戴：布鞋、帽子、绸缎

### 内联升

- 1853年（咸丰三年）赵廷创于东江米巷，后入大栅栏；专做千层底，原给官宦做朝靴，“内”指大内、“联升”取连升三级。千层底布鞋制作技艺为非遗，男/女/童/拖四季款，二楼常设布鞋文化展示。 暴走前门买一双千层底很应景。

### 盛锡福

- 前门大街55–57号（资料亦见57号）；1911年创于天津，30年代进北京。皮帽制作技艺非遗，冬季买貂/羊皮/礼服呢帽，平时看制帽工艺。

### 同升和

- 前门大街有店；1902年创于天津估衣街，做布鞋也做帽，礼服呢鞋、千层底、定做帽都行，北京级制鞋非遗。

### 瑞蚨祥

- 大栅栏核心老号（1893年孟洛川扩号，前身为章丘孟氏绸布业务）；真丝、宁绸、定制旗袍、中式套装，开国红旗面料供应商故事常被提到。买面料/做旗袍去大栅栏总店，比主街快消更“老”。
- 同片区还有谦祥益做中式服装/丝绸，属于“八大祥”体系。

马聚源若遇：老帽号，和“头戴马聚源、脚踩内联升”俗语对应，前门大栅栏周边可顺带认牌。

## 五、照相、茶馆、文娱老号

### 大北照相馆（前门大街2号）

- 1921年创号，1958年迁前门、2008年重开现址；早期戏装照出名，后来接大型会议团体照，中华老字号。拍全家福、戏装、证件照、老照片修复都行，营业约8:30–19:00。

### 老舍茶馆

- 大栅栏邻前门，1988年由1979年箭楼大碗茶摊发展而来；书茶馆、餐茶、清茶、相声评书一体，3300㎡左右，10:00–22:00。外地人听一段相声、喝盖碗茶最省事。

大观楼虽不算“老字号商品店”，但大栅栏南口、1905年前后放映《定军山》，称中国电影诞生地，和全聚德、同仁堂串成“前门商业文化”很合适。

中国书店、荣宝斋前门/琉璃厂方向有网点：中国书店做古旧书、碑拓、古籍修复；荣宝斋做文房、木版水印、装裱，属于文教类老号，不爱吃烤鸭的可以走这条线。

## 六、半天逛吃怎么排（不绕路）

- 纯吃线：前门箭楼拍照 → 全聚德30号（烤鸭）或都一处38号（烧麦） → 鲜鱼口天兴居（炒肝包子）/壹条龙（涮肉） → 吴裕泰42号冰淇淋收尾。
- 买手信线：张一元86号、吴裕泰42号（茶叶） → 天福号19号/月盛斋（酱肉） → 大栅栏内联升、盛锡福、瑞蚨祥（鞋帽绸缎） → 稻香村/六必居（点心酱菜）。
- 老商街文化线：前门主街大北2号 → 全聚德老门面墙 → 都一处 → 西进大栅栏同仁堂、内联升、瑞蚨祥 → 鲜鱼口小吃 → 老舍茶馆/大观楼。
