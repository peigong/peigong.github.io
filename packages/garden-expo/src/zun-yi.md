# 遵义园

北京园博园的遵义园在第九届中国（北京）国际园林博览会（2013年，丰台永定河片区）里归现代展园区，不走“遵义会议旧址复刻”的纯红色展馆路线，而是用“黔北农家＋丹霞水景＋茶农文化”做缩微新农村，主题叫“和谐黔北、锦绣家园”，面积1080㎡。

## 一、基本盘

- 届次/片区：第九届北京园博，现代展园；以当日园博园导览为准定位。
- 面积：约1080㎡，是城市展园里偏小的“院落型”而不是大山水型。
- 主题：和谐黔北、锦绣家园；载体是贵州“四在农家”（富在农家、学在农家、乐在农家、美在农家），不是单纯革命纪念园。
- 风格：黔北民居＋丹霞水体＋茶农院落，整体“白墙小青瓦、石墙朝门、彩色流水”，比西安汉风、鄂州铜镜、海口钟楼都更乡野、更生活化。

## 二、总体格局：朝门—茶农院—丹霞水—表演区

不按中轴礼制，按“进院看农家、绕水看丹霞、场外看花灯”组织：

- 入口八字朝门做对景和框景；
- 正对茶农之家二层白楼，作为全院核心；
- 侧后/院周做水漫丹霞彩色水流、石墙、黔北民居小品；
- 预留室外表演活动区，会期做花灯戏、品茗等互动。

设计上用了借景、障景、框景、对景、点景，地块小但层次不单薄。

## 三、主要景点

1）八字朝门（主入口）

黔北农村常见“朝门”，两侧墙体呈“八”字形外撇，不建牌坊、不建阙楼。功能有两层：一是进门先扩视野，形成纳气开口；二是民间取“八字敞开、海纳百川”的吉意。墙体、地面用灰白长条砖石，入口可挂红灯笼、放售茶招牌，乡集味很重。

2）茶农之家（核心建筑）

正对大门的二层小白楼，黔北民居元素全给齐：

- 外观：小青瓦、白粉墙、坡屋顶、雕花窗、转角楼；
- 结构：灰瓦尖顶＋暗红方柱＋白墙，挂“茶农之家”匾；
- 内部分区：堂屋、办公室、农家书屋、农家厨房；会期厨房可展示整体橱柜、煤气灶等新农村设施，强调“从土墙木板房到砖房”的居住变化；
- 外墙标语：用遵义农村花灯戏《十谢共产党》内容，讲吃、穿、住等生活变迁，是全书“红色＋新农村”的落点而不是单独搞会议叙事。

3）水漫丹霞（丹霞景观水体）

遵义园把赤水/黔北丹霞转成园林水景：水体用彩色水流模拟丹霞红层与溪谷，配石岸、石墙，形成“水漫丹霞”的看面。它不堆火山、不堆沙漠，而用红褐色石意＋浅水流，和遵义赤水丹霞、习水丹霞的地质名片呼应。

4）石墙与黔北民居小品

全院大量用本地石墙、毛石驳岸、白灰院墙，避免北方展园常用红墙黄瓦。转角楼、雕花窗、坡屋面做“组景”而不是单栋仿建；部分区域做黔北农家院坝感，可坐、可展、可拍照。

5）室外表演活动区

现代展园预留活动场地，会期两件事最典型：

- 花灯戏《十谢共产党》：当地农民创作，遵义园现场演出版，把红色叙事用贵州花灯小戏带出来；
- 品茗/售茶：以遵义绿茶、早春茶为卖点，游客坐“茶农家”喝新茶，配合农家书屋、茶事展板做互动。

6）特色植物与造型小品

展园列有“特色植物、特色造型小品”，整体走黔北乡野：耐北京气候的乔木打底，配茶篱/茶树意向、竹类、贵州常用观赏灌草；小品用茶具、灯笼、农具、石磨、楹联等。会期春天可突出“早春绿茶”的采茶语境。

## 四、文化主线怎么读

- 黔北民居线：八字朝门、小青瓦白墙、转角楼、石墙——看的是遵义/赤水/播州一带农村建房习惯，不是府城官式；
- 茶与绿色线：茶农之家＋品茗＋茶园植物，对应遵义茶（湄潭、凤冈、正安等绿茶产区）和“绿色家园”；
- 丹霞地质线：水漫丹霞把赤水丹霞世界遗产转成水景，不讲课、用颜色和大石头说话；
- 红色软表达：不建会议会址模型，而用《十谢共产党》花灯、茶农新房、书屋厨房，讲“革命老区变新农村”。

补充：别把它和后来其他城市园博的“遵义园”混了——有些园博遵义园会做遵义会议会址模型、四渡赤水、茅台陶罐、红娘子雕像；北京2013这版主体是小农家院＋丹霞水，红色是“新农村标语/花灯”而不是战场复原。

## 五、植物与材质

- 建筑：白粉墙、小青瓦、暗红木柱、雕花窗、石质朝门；
- 硬景：灰白长条砖石、毛石墙、丹霞色石、彩色流水；
- 水景：浅水漫流为主，红层意像强于大江大湖；
- 植物：以北京可露地养护的乔木灌木打底，茶花/茶篱意向、竹、贵州乡土观赏草花适量；冬季以建筑和白墙石景为主，夏季水景和绿植更出片。
