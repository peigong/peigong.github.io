# 蔡伦古法造纸

> 参考：[耒阳新八景推荐景点（十二）：蔡伦古法造纸作坊](https://www.leiyang.gov.cn/xxgk/szfxxgkml/gzdt/bmdt/20200214/i1035071.html)

蔡伦天下纸，竹海耒阳情。古法造纸作坊是蔡伦竹海的一处重要的人文景观。公元105年，时任尚方令的耒阳人蔡伦得到汉和帝的支持，历尽千辛万苦终于创造出一整套完善的造纸术，研制出了第一张用废麻和树皮做原料的植物纤维纸，时人称之为蔡侯纸。现在的造纸作坊建于2009年，模仿古代造纸作坊而建，古色古香，深度还原了古代造纸的场景。美国学者迈克尔?哈特在其《对历史最有影响的100个人物》中，把蔡伦排在第7位。评述说，“如果没有蔡伦就没有纸，我们很难想象今天的世界将会是什么样的状况。”

蔡伦古法造纸共分为九步：第一步，破料，从山上砍下嫩竹，再把嫩竹砍成一小截，并分扎成捆；第二步，沤料，把分扎成捆的嫩竹放入池中，倒入生石灰水，浸泡三个月；第三步洗料，取出浸沤之料，用泉水反复清洗三次，再浸泡月余；第四步，制滑料，也是制纸药，这是整个蔡伦造纸流程的核心技术，取山胡椒叶，经过舂捣、蒸煮等加工步骤所制成的一种绿色的粘稠性的液体，就是纸药；第五步，捣料，将洗净之料放入石臼中进行舂捣；第六步，打槽，将纸料和纸药放入木槽中，用木耙轻轻搅拌使其分布均匀；第七步，抄纸，手持抄纸帘放入木槽中轻轻一荡，抄纸帘上的一层薄薄的纸浆膜就是纸张，再把纸张层层叠放；第八步，分纸，把纸张榨干去水，再用竹镊挑起边角，把纸张张张分开；第九步，晾纸，把纸张晾晒干，便可用于书写了。
