# 四层

## T0 时刻

- 中国，点火倒计时。美国，起飞倒计时。
- 点火派，当发动机喷出第一缕火焰时，系统立即记录为T0时刻。设计源于我国火箭动力系统的独特结构，由于没有使用机械牵制装置，火箭能否离开发射台完全取决于发动机推力的自然累积，起飞瞬间存在几秒钟的动态调整期。
- 起飞派，得益于发射台上的机械锁扣（牵制释放装置）,火箭在点火后仍被固定，直到所有发动机达到额定推力，才解锁升空。牵制释放装置可以消除不同发动机之间推力不同步的影响，帮助工程师更精准的预判离地时间。
- 倒计时10秒，自动启动飞行软件。倒计时5秒，激活逃逸塔系统。
- 起飞12秒，程序转弯，调整飞行角度。
- 120秒，逃逸塔脱离。逃逸塔由塔架和两组发动机组成。
- 152秒，助推器脱离。
- 156秒，一级火箭脱离。
- 210秒，整流罩脱离。
- 577秒，二级火箭脱离。

## 神舟一号飞船

- 神舟一号飞船是我国第一艘无人试验飞船
- 1999年11月20日凌晨6时30分在酒泉航天发射场发射，同年11月21日凌晨3时41分顺利降落在着陆场。

## 人类基因组计划

- 人类基因组计划于1990年正式启动，由美、英、法、德、日和中国科学家共同参与
- 与曼哈顿原子弹计划和阿波罗计划并称为三大科学计划
- 于2003年提前完成，覆盖了人类基因组的99.99%
- 1号染色体包含基因数量最多，由150名英国和美国科学家组成的团队历时10年，才完成测序工作。
