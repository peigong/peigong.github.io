# 讲解提纲

## 中轴建筑

- 昭泰门（山门）
- 雍和门（天王殿），供有布袋尊者和四大天王塑像。
- 雍和宫（大雄宝殿、银安殿），明间上悬雕龙华带匾，中刻满、汉、蒙、藏四种文字所题“雍和宫”。殿内供有三尊青铜质泥金佛像，及蒙麻泼金十八罗汉像。
- 永佑殿（正寝殿、神御殿），明五暗十。白檀木雕佛像，中为无量寿佛（即阿弥陀佛），左为药师佛，右为狮吼佛。
- 法轮殿
- 万福阁

### 铜须弥山

### 法轮殿

- 一尊高6.1米的黄教创始人宗喀巴大师的铜坐像，塑于1924年，耗资20万银元，历时两年。
- 誉为雍和宫木雕三绝之一的五百罗汉山，全部由紫檀木精细雕镂而成。
- 金丝楠木雕成的木盆，据说当年乾隆帝呱呱坠地后三天，曾用此盆洗澡，俗名“洗三盆”。

### 万福阁

- 辽金时代的建筑风格
- 正中悬雕龙华带匾，上以满、汉、蒙、藏四种文字书“万福阁”。
- 阁内供奉一地上18米、地下8米，总高26米的木雕迈达拉佛（弥勒站像），是由七世达赖喇嘛的进贡礼品，用整棵名贵的白檀香木雕成。
- 据说乾隆帝为雕刻大佛，用银达8万余两，这尊大佛也是雍和宫木雕三绝之一。
- 还有一尊木雕三绝在万佛阁前东配殿照佛楼内，名金丝楠木佛龛，采用透雕手法，共有99条云龙，条条栩栩如生。
