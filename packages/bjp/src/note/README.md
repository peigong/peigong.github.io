# 讲解提纲

##  北京天文馆老馆（A馆）

- 由著名建筑师、设计师张开济主持。
- 室内装饰是由美术大师吴作人和周令钊等人完成的。
- 在北京天文馆开馆典礼上，北京市副市长吴晗致祝辞。
- 中国大陆地区最大的地平式天象厅

## 北京天文馆新馆（B馆）

- 由中国航天建筑设计研究院设计
- 外观上，呈现周边扭曲的“空间纹理”（这种现象是爱因斯坦的相对论所阐释的巨大质量天体迫使小质量天体扭曲变形，并吸引小天体坠入）。
- 扭曲的玻璃幕墙以独特的形态诠释着爱因斯坦的广义相对论和“虫洞”“弦理论”等现代天文学理论。

## 北京古观象台

- 古观象台是中国古代的皇家天文台。
- 建于明正统七年（1442年），是明清两代的国家天文台。
- 从明正统初年到1929年止，古观象台从事天文观测近500年，是现存古观象台中保持连续观测最悠久的。
- 天体仪制于康熙八年至十二年(公元1669-1673年)，由比利时传教士南怀仁监制。仪重3850千克，仪高2.735米，现位于北京古观象台台顶。

## 傅科摆

- 傅科摆在1957年和北京天文馆一起建造，在老馆的大厅，一进门就可以看到，黑色大理石贴面的圆形围墙，白色大理石摆盘上刻着时间和角度。摆锤是内部灌铅的铜球，重约170公斤。摆的方向随时间的变化在改变，它是用来证实地球自转的仪器，是法国青年傅科于1851年发明的，故称为“傅科摆”。
- 摆动平面偏转方向与纬度有关，在北半球顺时针转动，南半球逆时针转动，赤道上几乎不转。
- 在北京傅科摆摆动平面转动一周约37小时，两极旋转周期约24小时。
- 科里奥利力（Coriolis force），是对旋转体系中进行直线运动的质点由于惯性相对于旋转体系产生的直线运动的偏移的一种描述。
- 有关水槽之类的下水方向：例如马桶的下水方向确实受到科氏力的影响，但这种影响是微不足道的。马桶的下水方向更多地取决于马桶水槽的形状。其它类型的水槽亦如此。

## 行星的定义及分类

根据国际天文学联合会（IAU）在2006年提出的行星定义，一个天体要被认定为行星，必须满足以下三个条件：

- 围绕恒星运行：行星必须是围绕恒星运行的天体，这将其与其他不围绕恒星运行的天体区分开来；
- 流体静力平衡：拥有足够的质量，通过自引力形成近似球形的形状，这一标准将行星与小行星等不规则形状的天体区分开；
- 清空自身轨道周围区域，保证轨道内不存在其他行星：根据这一标准，行星必须有足够的引力来清除或吸引其轨道区域内的大多数其他天体，例如小行星或彗星。而冥王星由于其轨道附近存在大量柯伊伯带小天体，未能符合这一标准，因此被重新归类为“矮行星”。

### 行星

- 金星逆行自转，天王星自转轴近乎“躺倒”。
- 1859年伟烈亚力与李善兰合作翻译的《谈天》是中文文献中第一次介绍哥白尼的地动说，也是中文“行星”一词第一次出现。
- 古典概念的行星包括七颗，分别是阴阳五行——太阳、太阴(月球)，以及金星、木星、水星、火星和土星。
- 1781年，第七颗行星天王星被发现。
- 1801年，谷神星被发现，有长达49年的时间被称为“第8颗行星”
- 1850年，谷神星因尺寸太小，且发现一系列更小的同类型星体（即小行星），其行星地位被免除
- 1846年，第八颗行星海王星被发现
- 1930年，冥王星被发现，有长达76年的时间被称为“第9颗行星”
- 2006年8月24日的行星定义中，冥王星成为了一颗矮行星。

### 黄道

- 西方文明中，太阳的轨迹把黄道分作十二段，每月一段，每段一个星座组成黄道十二宫
- 中国文明中，太阳的轨迹把黄道分作四段，每个季度一段，即天空四象“青龙、白虎、朱雀、玄武”
- 太阴（月球）的轨迹把黄道分作28段，每天一段，对应天空的28个星宿

### 柯伊伯带

- 柯伊伯带位于太阳系的海王星轨道（距离太阳约30天文单位）外侧，在黄道面附近的天体密集圆盘状区域。
- 杰拉德·柯伊伯（1905.12.7―1973.12.24），荷兰裔美国天文学家，提出在太阳系边缘存在一个由冰物质运行的带状区域，为了纪念柯伊伯的发现，这个区域被命名为“柯伊伯带”。
- 2006年1月19日，第一艘以探索柯伊伯带为任务的航天器新视野号发射升空。
- 新视野号航天器已于2015年7月14日抵达了冥王星。
- 美国东部标准时2019年1月1日，新视野号在距离太阳43.4天文单位处飞掠名为“天涯海角”的柯伊伯带小行星2014 MU69。
