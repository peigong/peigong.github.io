# 锡冶炼的历史沿革和技术路线

锡冶炼的故事和铅、银不太一样。铅银的核心是“脱硫+捕集”，锡的核心则是——锡石本身就是氧化物（SnO₂），木炭直接还原就能出金属，这是它三千年技术路线几乎没变过的原因。变的只是炉型、燃料、富集手段和精炼精度。

## 一、古代源头：锡石 + 木炭还原，一步出锡

1. 锡为什么“好炼”

锡的主要工业矿物是锡石 SnO₂，是氧化物而不是硫化物。这意味着它不需要先焙烧脱硫，直接和碳一起加热就能还原：

SnO_2 + 2C \rightarrow Sn + 2CO

对比一下铅（PbS 需先氧化脱硫）、铜（CuFeS₂ 需多段焙烧）、银（伴生于铅矿），锡是古代最容易还原成金属的“重有色金属”之一——熔点只有232℃，沸点高达2603℃，液态区间在金属里最长，挥发损失极小。

2. 最早的锡冶炼证据：大井遗址

辽宁大井古矿冶遗址（夏家店上层文化，距今约2970年，相当于西周）给出了中国最早的锡冶炼实物链条：

- 矿石：含锡砷的硫化铜矿，矿物组合以黄铜矿 + 锡石 + 毒砂为主，含砷最高达15%
- 工序：死焙烧脱硫脱砷 → 椭圆形冶炼炉 → 人工造渣 → 鼓风管强化鼓风 → 木炭还原
- 产物：锡砷青铜（铜约75%、锡约20%、砷约5%），出土陶范证明可直接铸器

注意这里的关键：古人不是“炼纯锡”，而是“用锡石当锡源直接炼青铜”。纯锡的使用反而晚于青铜。

3. 商代锡料的远距离调配

近年安徽阜南迎水寺遗址的考古新发现更有意思。研究者在一块锡合金化渣里找到了十余颗未反应或部分熔解的锡石颗粒（直径超过500微米），据此确认商代匠人用两种方式产锡青铜：

- 点炼法（cementation）：锡石 + 铜料同炉
- 混合矿冶炼（co-smelting）：锡石矿 + 铜矿共炼

对渣中锡石做 U–Pb 定年后发现，中商偏晚阶段淮河中游的锡料来自1500公里外的大兴安岭南段锡多金属成矿带——商代青铜工业已经具备跨东北—华北—中原—淮河的远距离资源调配能力。

这是理解锡冶炼史的一个隐藏主线：锡矿分布极不均衡（全球集中在东南亚、玻利维亚、云南、康沃尔），所以锡冶炼史同时也是一部锡料运输史。

## 二、古代主流炉型：竖坑炉 + 风箱 + 木炭

中国南方（广西、云南）的古代炼锡工艺非常稳定，一直延续到民国：

“用上大下小、敞口竖炉，用手拉风箱鼓风，木炭还原的设备和方法，并延续到民国时期。”

这套设备和铅的竖炉很像，区别在于：

维度 | 古代炼铅 | 古代炼锡
---------------------------------------
原料 | 方铅矿 PbS | 锡石 SnO₂
前处理 | 必须焙烧脱硫 | 可直接入炉
还原剂 | 木炭 | 木炭
产物 | 含银粗铅 | 粗锡（常含铁“硬头”）
难点 | 硫、银分离 | 铁、砷分离

锡的古代难点从来不是“能不能炼出来”，而是怎么把铁、砷、锑除干净。

## 三、中国锡业的核心场域：云南个旧

1. 两千年采冶史

- 西汉：《汉书·地理志》载“益州郡贲古县，北采山出锡，西羊山出银、铅，南乌山出锡”——贲古即个旧
- 东汉：冲子坡古矿冶遗址出土锡锭、银饰、汉五铢、大量铜锡炉渣
- 明正德《云南志》：“锡，蒙自个旧村出”
- 清康熙、雍正《云南通志》：“设个旧厂，专收锡、银课税”

2. 近代工业化跃迁

- 1909年：设个旧锡务股份有限公司，派员赴南洋考察，聘英国冶炼工程师可奈克、德国工程师裴劳禄，向德商礼和洋行订购冶炼设备，1913年投产，揭开云南冶金工业机械化序幕
- 1910年：个旧锡产量6347吨，出口6195吨
- 1931年：云南炼锡公司成立
- 1943年：吕冕南发明新冶炼法，产出99.95%精锡，打破个旧锡须经外国机构化验才能出口的限制，只要有他的签名即可免检出口
- 1990年：云锡研制成功电热连续结晶机，被誉为“20世纪锡冶金工业最伟大的发明之一”

💡 个旧的这段历史，其实是整个中国近代有色金属工业化的缩影：从土炉木炭 → 引进反射炉 → 自主突破精炼设备 → 出口免检，走了不到一百年。

## 四、现代锡冶炼：四条主线

现代锡冶炼流程固定为预处理 → 还原熔炼 → 精炼 → 烟尘/炉渣处理。按原料和工艺分四条主线。

### 路线A：两段还原熔炼（传统主干）

锡精矿（SnO₂）
  → 一次熔炼（低温弱还原）
  → 粗锡（约90% Sn）+ 富渣（8-15% Sn）
  → 富渣二次熔炼（高温强还原 + 焦炭/石灰石）
  → 贫渣（<3% Sn）+ 硬头（Fe-Sn 合金，返回一次熔炼）

关键化学反应：

SnO_2 + 2C \rightarrow Sn + 2CO

FeO + C \rightarrow Fe + CO

铁被还原出来后和锡生成“硬头”（Fe-Sn 合金），是锡冶炼特有的中间产物。

### 路线B：还原熔炼 + 烟化挥发（现代主流）

富渣不二次熔炼，直接进烟化炉，通过氯化/硫化强化挥发，把锡以 SnO 或 SnS 形式挥发成烟尘回收，弃渣含锡可降到0.1%以下。

这一步是把古代“炉渣里丢掉的锡”反向捞回来，回收率从传统方法的~80%提到93%以上。

### 路线C：烟化富集 + 还原熔炼

针对低品位精矿（<30% Sn），先烟化富集到40%以上，再按路线A处理。适合玻利维亚脉锡、部分尾矿再选料。

### 路线D：电炉熔炼（含再生锡）

- 1938年扎伊尔建成第一座炼锡电炉
- 中国用于处理锡烟尘、二次资源为主，1979年柳州冶炼厂用400kVA矿热炉替代反射炉处理烟尘，锡直收率提高33.45%

《锡行业准入条件》明确：再生锡吨项目主设备电炉不得低于400kVA，年产锡锭不低于3000吨。

## 五、粗锡精炼：火法 vs 电解

还原出来的粗锡含铁、砷、锑、铜、铅、铋，必须精炼。

火法精炼五步走

1. 熔析除铁：232℃熔化，铁留在硬头里
2. 加硫除铜：Cu + S → Cu₂S 浮渣
3. 吹空气/蒸汽氧化：铁、锌、铅、砷成浮渣
4. 电热连续结晶除铅：利用 Sn-Pb 共晶（183℃），中国40年代工业化，这是个旧云锡的招牌技术
5. 加铝除砷锑：铝与砷锑生成高熔点化合物，加锯末搅拌上浮

⚠️ 第5步的浮渣遇水立即产生剧毒砷化氢（AsH₃），是锡冶炼最危险的操作环节。
电解精炼

以粗锡为阳极、纯锡为阴极，用氟硅酸锡-氟硅酸-硫酸体系电解液：

- 阴极电流效率 >95%
- 阴极锡纯度 99.95%–99.99%
- 阳极泥回收银、铋

## 六、二次资源：锡冶炼的“新战场”

锡是极易回收的金属——罗马时代希腊罗马文物里纯锡器极少，因为锡被反复回炉重熔。今天这个特性被放大成产业。

### 主要原料

- 废印刷电路板（WPCB，锡含量约4%）
- 废镀锡板（马口铁）
- 无铅焊料（Sn-Ag-Cu 系）
- 锡阳极泥、含锡冶炼渣

### 三条技术路线

路线 | 原理 | 适用场景
---------------------------------------
湿法酸/碱浸 | 盐酸浸出镀锡板，锡以 SnCl₂ 入液；碱浸焊料，锡成 Na₂SnO₃ | 电子废料、复杂合金
真空蒸馏 | 利用 Pb、Bi 蒸气压远高于 Sn | 深度脱铅脱铋，纯度可达99.99%
电解精炼 | 粗锡阳极选择性溶解 | 最终深度提纯

昆明理工大学在锡合金真空蒸馏基础理论及产业化上处于国际前沿。

## 七、古今技术渊源对照表

现代环节 | 古代源头 | 关键跃迁
---------------------------------------
锡石直接碳还原 | 竖坑炉 + 风箱 + 木炭 | 反射炉/电炉 + 富氧，控温精准化
青铜共炼（点炼/混合矿冶炼） | 商代迎水寺、西周大井 | 现代已分离为铜、锡两条独立工业
富渣二次熔炼 | 古法“渣中锡丢弃” | 从丢掉变成回收，回收率80%→93%+
烟化炉挥发 | 无直接对应 | 把炉渣中的锡反向富集，弃渣降至0.1%
电热连续结晶除铅 | 无 | 个旧云锡1990年独创，世界级发明
真空蒸馏脱铅铋 | 无 | 物理分离替代化学药剂，零废渣

## 八、一句话概括

锡冶炼的技术史，是围绕 SnO₂ 这一种氧化物，在“怎么把铁砷赶走、怎么把渣里的锡捞回来”这两个问题上做了三千年工程优化的历史。

- 古代给了最简解法：锡石 + 木炭 = 锡，所以锡是青铜时代最早被规模化利用的金属之一
- 近代个旧走出一条引进—消化—反超的路，电热连续结晶机是中国对世界锡冶金的最大贡献
- 现代锡冶炼的主战场已经从“从矿石里炼锡”转向“从废电路板、废焊料、冶炼渣里捞锡”——锡是少数几种“二次资源比原生矿更划算”的金属

📌 有个有趣的历史闭环：罗马人称锡为 stannum，最早指铅银合金的仿制品，4世纪才专指锡。而今天锡最大的用途是镀钢制马口铁——和两千年前罗马人“铜器镀锡防毒”的逻辑完全一样，只是把铜换成了钢。
