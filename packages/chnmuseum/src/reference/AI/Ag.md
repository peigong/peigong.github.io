# 银冶炼的历史沿革和技术路线

白银冶炼的历史，本质上是人类从“捡自然银”走向“从铅、铜、锌矿里顺带提取银”的技术演进史。它的核心逻辑三千年没变——用一种更容易熔化的金属（铅）当“捕集剂”把银带走，再把铅烧掉留下银；变的只是捕集剂、炉型、燃料和精炼手段。

## 一、古代源头：铅做捕集剂 + 灰吹法

1. 最初就不是挖天然银

天然银在自然界极少形成大块，多为细丝状，早期矿工容易忽略。真正能规模生产的，是含银方铅矿（PbS）——银以微量溶解在铅里。

考古证据很硬：伊朗高原 Tepe Sialk、叙利亚 Habuba Kabira、安纳托利亚东部，都出土了公元前四千纪的氧化铅（litharge，PbO）残块。这种东西自然界不存在，只有灰吹法才会产生，等于给“灰吹法源头”盖了章 。

2. 灰吹法的两步逻辑

第一步 熔炼：含银方铅矿 + 木炭 → 含银粗铅（银溶在铅里）
第二步 灰吹：粗铅放灰吹炉鼓风 → 铅氧化成 PbO 流走/挥发
              → 剩下银珠

铅熔点 327℃、沸点 1749℃，银熔点 962℃、沸点 2162℃——铅先被氧化带走，银留下，这就是灰吹法的全部化学原理 。

到公元前1000年左右，地中海世界银产量已经大到把银价从金的 1/4 压到 1/12，伊朗中部单是冶炼炉渣就堆了几十万吨 。

3. 中国路径：入铅 + 吹灰

宋代赵彦卫 《云麓漫钞》记下了完整工序：

“用臼捣碎，再上磨，以绢罗细，然后以水淘，黄者即石，弃去；黑者乃银，用面糊团入铅，以火锻为大片……俟三两日再煎成银。”
关键词是“入铅”——主动加铅把矿石里的银全部捕出来，再灰吹。这一步是中国古代炼银最核心的原创性操作 。

明代宋应星 《天工开物·五金》则把工序写成“寻苗—采矿—捣碎淘洗—层炭铺矿鼓风熔炼—铅沉底、渣浮面”，与宋代记载一脉相承 。

4. 中国的一次关键技术跃迁：铁还原法

7世纪前后，中国工匠开始用铁还原法（IRP）处理含银方铅矿：

PbS(Ag) + Fe \rightarrow FeS + Pb(Ag)

不用先焙烧成氧化铅，一步直接出含银铅。河北曲阳12—13世纪遗址考古证实，这套方法在金代已经用煤炭作燃料、在耐火坩埚里外加热执行——背景是华北森林砍伐危机、木炭不够用，逼出了“煤炭+铁还原+坩埚”的组合 。

💡 这个时间差很有意思：欧洲要到18世纪才把铁还原法用于铅银冶炼，中国早了约1100年 。

## 二、近代转折：混汞法与汞齐化

1571年，汞齐化法传入安第斯山区的波托西银矿。在此之前，印第安人用小熔炉+羊驼粪燃料+铅捕集，只能吃富矿，银产量一路下滑。汞齐化法让低品位矿也能提银，波托西产量才重新抬起来 。

日本明治维新后第一批引进的西方技术也是混汞法，用于佐渡、生野等官营银矿 。

这一阶段的意义在于：银不再是“富矿专属”，低品位大规模开采成为可能，为后来浮选+湿法铺了路。

## 三、现代技术路线：三条主干并行

现代白银绝大多数不是独立银矿生产的，而是铅、锌、铜冶炼的伴生副产品。三条路线按原料分工，不是替代关系。

### 路线A：火法——阳极泥回收（最主流）

含银铜/铅精矿
  → 闪速熔炼 / 富氧底吹
  → 粗铜 / 粗铅（银进金属相）
  → 电解精炼
  → 银留在阳极泥中（富集30-50倍）
  → 硫酸化焙烧 → 水浸脱铜 → 还原熔炼得贵铅
  → 氧化精炼 / 电解 → 99.99% 成品银

阳极泥里银以单质或 Ag₂Se、Ag₂Te、AgCl 形式存在，成分随原料波动很大，所以每家厂的配方都要单独调 。

### 路线B：烟尘挥发富集（近年发展的工艺）

铅银渣（锌/铅冶炼中间产物）用侧吹浸没燃烧熔池熔炼 + 氯化强化挥发，让 Au、Ag 以烟尘形式跑出来，烟尘返回 ISP 烧结系统，银被铅捕集后最终在铅阳极泥里回收 。

这其实是古代“铅捕集”逻辑的现代变体——只不过捕集对象从矿石变成了烟尘。

### 路线C：湿法——氰化浸出 + 置换

原生银精矿（或阳极泥焙烧渣）
  → 稀 NaCN 溶液 + 空气（碱性）
  → Ag + 2CN⁻ → [Ag(CN)₂]⁻ 溶解
  → 加锌粉置换 → 银粉沉淀

辉银矿（Ag₂S）比金难氰化，所以要用 0.2–0.6% NaCN、延长浸出、加大充气；氯化银（角银矿）反而好浸 。

中国还独创了矿浆电解法处理多金属共生精矿：在氯化钠矿浆里通直流电，铅、银溶解率可达 97–99% 。

### 三条路线的渊源对照

现代工艺 | 古代源头 | 关键跃迁
---------------------------------------
火法阳极泥 | 灰吹法（铅捕集银） | 电解替代人力鼓风，富集倍数从倍级到 30–50 倍
烟尘挥发 | 焙烧—熔炼的挥发损失 | 把“损失”反向利用成富集手段
湿法氰化 | 无直接对应 | 19世纪化学工业催生的全新路线

## 四、一条贯穿三千年的主线

如果把时间轴拉通，白银冶炼的技术逻辑其实只有两次根本性变化：

第一次（公元前四千纪—公元7世纪）：发现铅能当银的载体，灰吹法把“从矿石直接提银”变成“两步走”。

第二次（19世纪至今）：发现银可以不经金属相、直接在溶液里络合提取，氰化/湿法诞生；同时伴生矿综合回收让银从“主角”变成“副产品”。

中间那一千多年——铁还原、煤炭坩埚、混汞、浮选——都是在“怎么更省燃料、怎么吃更低品位的矿”这两个约束下做的工程优化，底层化学没动过。

📌 一句话概括渊源：灰吹法给了白银冶炼的“形”，伴生矿综合回收给了它今天的“体”，湿法化学给了它第三条出路。
