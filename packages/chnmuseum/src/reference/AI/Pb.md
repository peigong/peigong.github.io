# 铅冶炼的历史沿革和技术路线

铅冶炼的历史沿革，本质上就是人类不断回答同一个问题的过程：怎么把方铅矿（PbS）里的铅从硫和脉石里拆出来。三千年来，这个问题的答案改过很多次，但底层化学反应始终是——先让硫跑掉（氧化），再把氧化铅还原成金属铅。

现代的富氧底吹、基夫赛特、卡尔多炉，看上去很"高科技"，其实都是这条古代逻辑的强化版：把"焙烧"和"还原"两步压进一个炉子里做，用氧气替代木炭鼓风而已。

## 一、古代源头：方铅矿的三条原始解法

古代铅矿石几乎全是含银方铅矿（PbS）。明代宋应星《 《天工开物》·五金》把铅矿分成三种："银矿铅""铜山铅""章节铅"，其中"章节铅"就是方铅矿本体，"银矿铅"是含银的方铅矿——古人对矿石分类已经相当精细 。

面对 PbS，古代工匠摸索出三条路：

路线1：敞炉直接氧化熔炼（最原始）

把方铅矿放在氧化性气氛的敞炉里直接烧：

2PbS + 3O_2 \rightarrow 2PbO + 2SO_2

PbS + 2PbO \rightarrow 3Pb + SO_2

第二步是关键——硫化铅和氧化铅自己发生交互反应，直接出金属铅，不需要额外加还原剂。这是最"省事"的一条路，但只能吃富矿，回收率低 。

路线2：焙烧 + 竖炉碳还原（传统主流）

方铅矿 → 先焙烧成 PbO（脱硫）
       → 进竖炉 + 木炭/焦炭还原
       → 粗铅

这条路线是后世工业化的直系祖先。焙烧阶段把硫氧化成 SO₂ 排走，造渣阶段让 PbO 与 SiO₂、FeO 形成低熔点硅酸盐熔体，粉矿烧结成多孔硬块，竖炉里焦炭燃烧提供热量和还原气氛 。

路线3：铁还原沉淀熔炼（中国的独门绝技）

关键反应：

Fe + PbS \rightarrow FeS + Pb

不用先焙烧，直接把铁屑和方铅矿混在一起加热。利用铁对硫的亲和力大于铅这一化学事实，把铅从硫化物里"挤"出来。反应后按密度分层：铅沉底、硫化铁居中、炉渣浮面，所以又叫"沉淀熔炼法" 。

河北曲阳燕川遗址的考古证据很硬：

- 筒状坩埚 + 煤渣碎块 → 用原煤外加热
- 坩埚渣里发现 1.3cm 的金属铁颗粒，芯部是低碳钢、表面脱碳成熟铁 → 证实装料时加了铁屑
- 铅颗粒银含量 >1% → 产品是含银铅锭，后续再灰吹提银 

这条路线在宋金时期华北快速扩散，直接动因是森林砍伐危机——木炭不够用了，煤炭+坩埚外热+铁还原的组合完美绕开"煤不能直接进高炉"的技术难题。铅银冶炼是"次一级木炭用户"，被迫先试煤；冶铁业规模大、惯性大，改用煤反而拖到清代 。

## 二、铅银同源：灰吹法把两条冶炼史焊在一起

这条渊源必须讲清楚，否则看不懂后面为什么铅厂总是顺带产银。

亲硫性决定了铅银共生——银和铅都是亲硫元素，在火山热液里一起形成硫化物，一起沉淀富集。自然界约 75% 的银产量来自铅矿，方铅矿含银通常可达 1%，富的直接当银矿用 。

所以古代几乎没有"纯炼铅"这回事，炼铅就是为了顺手拿银。古希腊劳里昂银矿（前600—前300年）出产的 9000 吨白银，全部走"方铅矿焙烧→熔炼出铅银合金→灰吹分离"这条路，最终铅里残银能压到 0.02% 。

灰吹法的化学原理（《天工开物》叫"沉铅结银"）：

铅银合金 + 鼓风升温
→ 铅氧化成 PbO（密陀僧），下沉进炉灰
→ 银不氧化，富集在灰面上
→ 反复几次，银提纯

利用的就是铅银互熔、但铅易氧化而银不氧化这一差异 。

💡 这条技术同源关系一直延续到今天：现代铅厂仍然在粗铅火法精炼/电解精炼时，把金银富集进阳极泥统一回收——灰吹法的现代版。

## 三、近代工业化：从敞炉到鼓风炉

时间线上的关键节点 ：

- 17世纪：欧洲铅生产初具规模
- 1853年：俄罗斯首次用鼓风炉熔炼铅矿石
- 1882年：奥地利用膛式炉生产粗铅
- 1888年：比利时霍博肯建成火法精炼系统
- 20世纪50年代起：传统火法污染重、硫回收难、能耗高，各国开始研究直接炼铅法
- 70—80年代：基夫赛特（KIVCET）、氧气底吹（QSL）、艾萨（ISA）、闪速熔炼先后工业化

中国这边的关键节点 ：

- 1985年：白银有色引进 QSL 法，1992年投产
- 1999年：云南曲靖引进 ISA 富氧顶吹
- 2003年：西部矿业引进卡尔多炉
- 2008年：江铜、株冶引进基夫赛特
- 水口山 SKS 法：1982年立项自研，1995年成功，是我国自主的直接炼铅工艺，解决了低浓度 SO₂ 烟气和铅尘污染两道行业难题，后推广到印度、越南

## 四、现代两条主干路线

### 路线A：传统烧结—鼓风炉（正被淘汰）

铅精矿 → 配料制粒
       → 带式烧结机焙烧（脱硫 80%+，粉矿成块）
       → 鼓风炉 + 焦炭还原
       → 粗铅（95%–98%）→ 火法精炼 → 精铅

化学主线 ：

焙烧段：2PbS + 3O₂ → 2PbO + 2SO₂
        3PbSO₄ + PbS → 4PbO + 4SO₂（硫酸盐交互反应）
还原段：PbO + CO → Pb + CO₂

缺点很致命：流程长、焦耗大、烧结烟气 SO₂ 浓度低难制酸、铅尘污染重。国内新建产能基本不再采用 。

### 路线B：直接炼铅（主流）

核心变化：把"焙烧"和"还原"压进同一个熔池里完成，用富氧喷枪强化氧化放热，基本实现自热熔炼。烟气 SO₂ 浓度高，直接进制酸系统 。

四大主力工艺对照 ：

工艺 | 炉型 | 特点
---------------------------------------
富氧底吹（SKS/QSL） | 卧式圆炉，底吹喷枪 | 连续作业，国产化成熟，国内应用最广
基夫赛特（KIVCET） | 电炉 + 闪速反应塔 | 对复杂矿、杂料包容度强，投资大
艾萨（ISA）/ 奥斯麦特 | 顶吹浸没喷枪 | 原料适应性广
卡尔多炉 | 倾斜旋转转炉 | 间歇式，灵活处理废铅、含铅渣，适合小批量多品种

生态环境部的《铅锌冶炼业污染防治技术政策》明确鼓励新建项目采用基夫赛特、SKS、ISA、Ausmelt、QSL 等先进工艺 。

### 路线C：湿法（只存在于实验室）

用溶剂把铅溶出再电解回收，理论上可行，但至今未实现工业化 。原因很现实：铅的目标市场成本敏感，湿法的药剂消耗和流程复杂度算不过账。

## 五、技术路线的渊源地图

把古今串起来看，脉络非常清楚：

现代工艺环节 | 古代对应 | 关键跃迁
---------------------------------------
烧结焙烧（脱硫成块） | 敞炉氧化 / 先焙烧后竖炉 | 带式烧结机 + 强制抽风，SO₂ 可回收制酸
鼓风炉焦炭还原 | 竖炉木炭还原 | 热风 + 富氧，焦比大幅下降
富氧底吹直接炼铅 | 敞炉一步出铅 | 喷枪强化传质，氧化放热自热化，取消烧结段
铁还原沉淀熔炼 | 坩埚铁屑置换 PbS | 现代仅少量用于特殊物料，工业上已不是主流
粗铅火法/电解精炼 + 阳极泥 | 灰吹法提银 | 电解替代人力鼓风，金银富集倍数从倍级到数十倍

## 六、一句话概括

铅冶炼的技术史，就是围绕 PbS 这一种矿物，在"脱硫—还原—分离杂质—顺带收银"四个问题上不断做工程优化的历史。

- 古代给了三条解法（直接氧化、焙烧还原、铁还原沉淀），其中焙烧还原活成了现代主干
- 银的伴生关系让灰吹法和铅冶炼焊死在一起，这条同源线今天还在阳极泥环节继续
- 现代直接炼铅不是在发明新化学，而是把古代两步走压成一步、用氧气替代风箱

📌 有个容易被忽略的细节：中国铅冶炼在宋金时期就用上了"煤炭+坩埚+铁还原"这套组合，比欧洲出现同类铁还原工艺早约 1100 年——驱动力不是技术超前，而是华北森林砍光了，工匠被迫用煤，结果误打误撞走出了自己的路 。
