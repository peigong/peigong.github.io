# 科学再发现

## 科学发现与问题链

科学始于问题，科学研究就是解决一个接一个的问题。

### 千年追光遇到折射定律

- 光折射的规律是什么？
- 圆盘测角，希腊，托勒密，最早的光折射定量测量实验。第一次把测量记录、制表归纳的科学方法应用于早期科学研究。
- 水镜之迷
- 德国，开普勒，破解望远镜成像缺陷。提出全反射的概念。
- 荷兰，斯涅耳，1621年。光学从经验观察向精确数学定律的转折。
- 寻踪幻影

### 折射定律的数学预言

- 光为什么这样折射？
- 介质变奏曲
- 理论能够解释现象，但未必是正确的。
- 笛卡尔假设，光在玻璃或水里比在空气中跑得更快。
- 1661年，费马，最短时间原理。光怎么知道哪条路时间最短？
- 从不同的假设出发，却意外地得到了同一个正确的结论。
