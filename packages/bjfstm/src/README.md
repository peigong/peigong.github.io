# 北京未来科技馆

北京未来科技馆（Beijing Future Science and Technology Museum），是中国北京市延庆区境内的科普场馆，由北京世园公园原生活体验馆改造而成。

北京未来科技馆建筑面积约2.1万平方米，布展面积1.3万平方米。场馆定位为综合性科普教育新阵地，设有地球家园、万物法则、数字时代、星际征程、未来已来五大主题展厅，核心展项为位于“未来已来”展厅的亚洲首个沉浸式低重力体验馆。
2026年9月20日，北京未来科技馆“未来已来”展馆竣工；9月30日，北京未来科技馆对外开放运营。

## 历史沿革

- 2017年8月，原2019年中国北京世界园艺博览会生活体验馆开工。
- 2018年1月4日，原生活体验馆钢结构封顶。
- 2019年4月29日，北京世园会开园，原生活体验馆同步开放。
- 2024年8月1日，延庆区对北京未来科技馆规划建设情况进行调研工作。
- 2025年7月24日，北京市人民政府新闻办公室举行“一把手发布·京华巡礼”系列主题新闻发布会，会上提及将“生活体验馆建成未来科技馆，聚焦人工智能、低碳科技的应用体验，成为青少年科普教育实践基地”。
- 2026年7月6日，世园遗产会后利用城市更新组团项目亮相2026北京城市更新推介会，项目拟围绕科技与生态两大主题，依托生活体验馆及周边国际展馆，打造科技研学片区；9月20日，北京未来科技馆“未来已来”展馆竣工；9月30日，北京未来科技馆开馆运营，并举行开馆仪式。

## 建筑布局

北京未来科技馆建筑由16个相对独立的单元模块组成，每个模块都是长宽27米、层高6米的方正空间。16个模块由纵横交织的街巷网络组织起来，形成一个棋盘状的平面格局，其中8个模块由室内街巷组成一个功能联系更紧密的展馆；6个独立展馆模块分布在它的周围；2个模块被作为室外集会的景观广场。场馆主体分上下两层，建筑面积约2.1万平方米，布展面积1.3万平方米，共有214个展览项目，总体划分为主展馆、商业合作空间、创客工坊、临展厅、独立儿童探索乐园、科学主题餐厅及多功能厅7大功能模块。馆内设有五大主题展厅，依次为地球家园、万物法则、数字时代、星际征程、未来已来，覆盖自然生态、基础科学、数字科技、航天探索、未来科创等领域，其中地球家园、万物法则、数字时代展厅位于展馆一层，星际征程、未来已来展厅位于展馆二层。

## 建筑特色

北京未来科技馆由原北京世园公园生活体验馆改造而成，建筑以“田园、村舍、市集”为创作构思，营造出一副“留树成荫、阡陌交通、九曲花坡、果道飘香”的诗意田园生活图景。设计依托柳荫路，参考传统北方村落的尺度，建立起一个“青砖铺地，尺度宜人”的纵横交织的街巷网络，营造出一片开放的生活聚落。为了顺应整个园区的空间态势，设计把建筑体量处理成东北高西南低的态势，面对园区打开，形成了高低起伏、错落有致的空间形态。建筑群外界面选用石笼墙、镂空砖墙、夯土墙、木板墙、云纹玻璃幕墙的外墙装饰，反映延庆地区建筑特征，与城市和山水格局相呼应。经改造升级后，整体建筑以“方舟启程”为设计理念，入口处设置一标志性星门。简洁硬朗的现代造型，与周边园林景致自然相融。

## 展出内容

北京未来科技馆以“探索科学、预见未来”为定位，以“见天地”“感智慧”“创未来”为布展逻辑，以构建“未来学习中心”为核心理念，以优质科教实践内容为战略锚点，以启发式问题为引领，打造“终身学习”生态，立足前沿科普理念，融合沉浸式体验与探究式教学，填补区域高端互动科普场馆空白，为北京市民、青少年群体打造集科技展示、研学实践、创新探索于一体的综合性科技教育新阵地。

### “地球家园”展厅

“地球家园”展厅以时间顺序回溯地球数十亿年的漫长过往，探寻星球诞生、生命演化、生态存续的科学奥秘。展厅以沉浸式交互展项，把地质、生物课本知识变得生动可感。展厅中序章讲解了地球从诞生到孕育生命的过程；“蓝色脉动”展区展示植物光合作用过程及海洋的“鲸落”现象，并展示“红树林、盐沼、珊瑚礁”三大滨海生态系统；“生命赞歌”展区回望地球生命跌宕起伏的演化史，经历灭绝与新生，生命不断适应环境变迁的过程；“岩石旅程”展区展现岩浆冷却、风化侵蚀、沉积变质，岩石在地质作用下不断转换形态，塑造山川地貌的过程。

### “万物法则”展厅

“万物法则”展厅以声、光、电、力、数理几何与传统智慧串成一条探索路线，让游客在互动中读懂万物运行背后的法则。“声控水流”展项通过让游客发声，传感器捕捉声波，实时控制水流形态与节奏，实现让声音“指挥”水流；“光纤传输”展项展示全反射原理，说明现代通信如何以光速传递海量信息；“电磁炮”展项通过通电线圈产生强磁场，推动弹丸高速射出，让游客直观看到电能如何转化为动能；“撬动地球”展项展示全反射原理，说明现代通信如何以光速传递海量信息；“莫比乌斯高速公路”展项把一条纸带变成“单面公路”并让小车在其表面行驶，让游客在趣味轨道中理解拓扑、曲面与空间连续性，感受数学几何突破直觉的奇妙魅力；“拓扑游戏”展项集合鲁班锁、魔幻三角、梵天塔、九连环、华容道、节省套等益智游戏。

### “数字时代”展厅

“数字时代”展厅以“溯源数字起源、探秘智能科技、解锁未来算力”为核心脉络，串联数字通信、智能驾驶、智能机械三大核心科技领域。其中“摩尔斯电码”展项设置趣味实操体验装置，参观者可亲手敲击信号、编码解码，直观感受“滴答”信号如何转化为有效信息；“智驾汽车”展项目拆解自动驾驶的科技内核，通过实物模型、图文拆解和动态演示，清晰展示传感器、车载芯片、控制系统、雷达等智驾核心部件的功能与运作逻辑；“机械手臂”展项通过机械臂互动展示，生动呈现人工智能与机械控制技术的融合应用，依托精准的数字算法与传感控制系统，可完成精准抓取、轨迹运动、动态响应等一系列精细动作。

### “星际征程”展厅

“星际征程”展厅分为两大主线：一条是宇宙天体之旅，认识恒星、行星、卫星与神秘黑洞；另一条是中国航天之路，以时间叙事梳理中国航天发展脉络，从火箭轰鸣到空间站安家，见证中国人挣脱地心引力、奔赴星辰大海的历程。其中“太阳系”展区展示八大行星的模型，游客可体验行星秤、月球漫步装置；“银河训练营”展区展示舱外航天服模型，游客可体验离心机、平衡训练仪等设备，还原航天员严苛的训练日常；“星际大穿越”展区展示长征二号F运载火箭模型。展厅还设置黑洞模型以及“引力冲浪”互动项目。

### “未来已来”展厅

“未来已来”展厅循着人类深空探索的发展脉络，以实物沙盘、数字互动、情景剧场、低重力体感体验相结合的形式，让观众从地球出发，沉浸式探访月球、火星，近距离触摸前沿航天科技，感受深空探索的独特魅力。其中“探月之路”展区复原月球实景地貌，清晰标注中外探测器经典着陆点位，带领观众读懂月球作为人类迈向深空起点的重大意义；国际月球科研站沙盘完整展示月球南极科研站各项功能模块；“登陆火星”展区梳理人类火星探测的曲折历程，重点展示天问一号一次性实现环绕、着陆、巡视的重大航天成就；展厅引入亚洲首个沉浸式低重力体验馆，依托自研吊轨和姿态捕捉系统，依靠力学补偿模拟月球、火星的重力环境，还原地外行走感受。
