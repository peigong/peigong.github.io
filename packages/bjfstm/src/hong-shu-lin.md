# 红树林生态系统

红树林生态系统一般包括红树林、滩涂和基围鱼塘三部分。一般由藻类、红树植物和半红树植物、伴生植物、动物、微生物等因子以及阳光、水分、土壤等非生物因子所构成。

分解者种类和数量均较少，且以厌氧微生物为主，有机体残体分解不完全。消费者主要是喜湿鸟类尤其是水鸟和鱼类，底栖无脊椎动物、昆虫，两栖动物、爬行动物亦较常见，哺乳动物种类和数量较少。

中美两国科学家最新联合研究表明，全球红树林生境较为破碎，截至2020年，全球红树林斑块约有33.7万个，其中95%以上斑块的面积小于1平方千米。 

## 简介

红树林是生长在热带与亚热带海岸潮间带或河流入海口的湿地木本植物群落，富含单宁酸，一旦刮开树皮暴露在空气中，就会迅速氧化成红色，故被称为“红树林”。红树林生态系统是由红树植物、半红树植物、伴生植物、动物、微生物及无机环境组成的开放程度最高的生态系统之一。在红树林生态系统中，主要植物种为红树、红茄莓、角果木、秋茄树、木橄、海莲等。它们具有呼吸根或支柱根；当果实在树上时种子即可在其中萌芽成小苗，然后再脱离母株，下坠插入淤泥中发育为新株（胎萌习性）。中国福建、台湾地区、广东、广西部分沿海滩涂地区均有分布，也存在于印度、马来西亚、西印度群岛和西非。

我国现有红树植物37种（其中真红树植物26种、半红树植物11种）。

红树林生长在海陆交界的生态过渡带上，有“海岸卫士”“海洋绿肺”的美誉。红树林生态系统是全球生产力最高、生物多样性最丰富的生态系统之一。精准的空间分布信息是评估红树林生态系统健康状况及实施保护策略的关键。

## 生境特征

截至2020年，全球红树林总面积约为14.5万平方千米，其中亚洲地区红树林资源最为丰富，约占全球总面积的39.2%；印度尼西亚红树林面积约2.9万平方千米，居各国之首。全球红树林生境较为破碎，约有33.7万个斑块，其中95%以上斑块的面积小于1平方千米。

我国红树林天然分布于海南至福建福鼎（北纬27°16′），人工引种北界已至浙江舟山（北纬30°）。根据近年监测，我国红树林主要分布在广东、广西、海南、福建、浙江及香港、澳门、台湾地区。其中，广东省红树林面积最大，占全国总面积的40.22%，其次为广西（32.9%）。截至2023年底，我国红树林面积已从本世纪初的2.2万公顷恢复增长至约3万公顷（45.45万亩），成为世界上少数红树林面积净增加的国家之一。

我国现有海南东寨港、广西山口、广东湛江、福建漳江口、广西北仑河口5处以红树林为主的国际重要湿地。其中，广东湛江红树林国家级自然保护区是我国红树林面积最大、分布最集中的自然保护区，红树林面积达7228公顷。

## 生态价值

1. 红树林是生物的理想家园

由于红树林具有热带、亚热带河口地区湿地生态系统的典型特征以及特殊的咸淡水交迭的生态环境，为众多的鱼、虾、蟹、水禽和候鸟提供了栖息和觅食的场所。因此，红树林蕴藏着丰富的生物资源和物种多样性。

红树林是候鸟的重要的中转站和越冬地。据统计，每年在深圳湾红树林湿地停歇和觅食的冬候鸟及过境鸟约有10万只，超过190种。

2. 天然的海岸防护林

红树植物的根系十分发达，盘根错节屹立于滩涂之中。红树林对海浪和潮汐的冲击有着很强的适应能力，可以护堤固滩、防风浪冲击、保护农田、降低盐害侵袭，对保护海岸起着重要的作用，为内陆的天然屏障，有“海岸卫士”之称。

3. 净化海水

红树林可净化海水，吸收污染物，降低海水富营养化程度，防止赤潮发生。

4. 促淤造陆

红树林在海滩上形成了一道樊篱，发达的支柱根加速了淤泥的沉积作用。随着红树群落向外缘发展，陆地面积也逐渐扩大。

5. 科研、教育、生态旅游

红树林是最具特色的湿地生态系统，兼具陆地生态和海洋生态特性。其特殊的环境和生物特色使得红树林成为自然的生态研究中心，对科普教育、发展生态旅游业也有积极作用。

## 威胁与挑战

根据世界自然保护联盟（IUCN）2024年5月发布的《生态系统红色名录》首次评估，世界上一半以上的红树林生态系统面临崩溃的危险，近20%的红树林处于高风险，被列为濒危或极度濒危。

在中国，一些地方的红树林保护仍面临挑战。2023年，中央第三生态环境保护督察组督察海南省发现，海口市东寨港国家级自然保护区缓冲区、实验区内仍违法存在约560亩养殖塘、7个渔船临时停靠点，上百艘渔船随意进出。临高县彩桥红树林自然保护区内有约400亩养殖塘未清退，且保护区内900余株红树林自2019年以来陆续枯死未及时处理。三亚河红树林自然保护区内建成篮球场、喷泉广场、停车场等设施，侵占保护区约109亩。儋州市光村镇位于生态保护红线内21.9亩红树林被陆续砍伐，临高县博厚镇马袅湾生态保护红线内约6亩红树林被砍伐破坏。这些问题暴露出部分地区存在规划缺失、监管不到位、保护意识淡薄等管理挑战。

## 保护与修复

中国已施行《湿地保护法》，并将红树林纳入生态保护红线严格管理。2020年8月，自然资源部与国家林业和草原局联合印发《红树林保护修复专项行动计划（2020—2025年）》，目标为营造和修复红树林。截至2023年底，全国已营造红树林约7000公顷（约10.5万亩），修复现有红树林约5600公顷（约8.4万亩）。

具体保护修复措施包括建立自然保护区、退塘还林还湿、人工造林、生态修复、有害生物防治等。同时，利用卫星遥感、无人机、智能水闸等智慧监测技术进行监管。

广东“十四五”以来整治修复海岸线超200公里，新营造红树林面积居全国首位。湛江金牛岛红树林片区开展生态修复与科普旅游，探索“红树林+”生态产业。深圳福田红树林应用智能水闸系统，并完成全国首单红树林保护碳汇交易。海南开展大规模退塘还林工程，例如东寨港保护区清退养殖塘，恢复种植红树林。

2024年，国际红树林中心在深圳正式成立，成为全球红树林保护合作的平台。

中国积极探索红树林生态价值实现路径，包括开发碳汇交易（如湛江、深圳、惠州等地完成多笔全国首单交易）、发展生态旅游、推广“种养耦合”模式等，推动“绿水青山就是金山银山”的实践。
