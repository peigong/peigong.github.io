# 公共区域

## 岁寒三友

- 中国盆景大师周国梁创作完成。
- 博物馆基础位于首钢废弃钢渣填埋场，配石取自挖出的钢渣组合而成。
- 北宋苏轼被贬黄州时曾以松、竹、梅为“三益友”
- 宋·林景熙《王云梅舍记》：“即其居累土为山，种梅百本，与乔松修篁为岁寒友。”

## 青莲朵

- “瘦、皱、漏、透”，文人赏石标准的体现。
- 800多年历史的太湖石
- 原系南宋临安（今杭州）德寿宫中故物，原名“芙蓉”。
- 南宋高宗赵构曾于德寿宫向孝宗介绍此石。
- 明代画家孙杕、蓝瑛合作绘制《梅石图》并刻碑立于石旁。
- 乾隆十六年（1751年）奉皇太后第一次南巡时，在杭州吴山的宗阳宫游览，发现此奇石
