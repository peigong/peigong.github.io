# 救驾台

## 黄三泰救驾康熙的经过

故事底色是「康熙行围打猎遇虎，镖客飞镖打虎」。

按《彭公案》第二十八回的讲法：

康熙到南苑大红门一带行围，场中放出的猛虎扑向御驾；

黄三泰当时本是绿林老辈，在场观猎，掏出「迎门三不过」飞镖，先打虎左肋，再补一镖前胸，虎当场毙命；

康熙召见，黄三泰下马弃刀跪拜，自陈本是绿林、只劫贪官，如今洗手退隐；

康熙看他年届花甲仍有这身手，龙心大悦，赐黄马褂，黄三泰从此号称「黄马褂」。

戏曲本《九龙杯》（又名《庆贺黄马褂》）也是同一套开头：

康熙帝在金沙滩射猎，为猛虎所窘……黄三泰用飞镖毙虎，因此脱险，钦赐黄马褂。

救驾之后的衍生情节

评书里还接了一段「画蛇添足」：

黄三泰受赏时当面夸口——「日后大内丢一草一木，都在某身上」。

结果宫里「九龙玉杯」被盗，康熙真让他追赃，限期内交不出就要问罪。

黄三泰只好借自己六十大寿设宴，挂出黄马褂镇场子，请各路绿林来喝喜酒，实则套话，最后逼出杨香武承认盗杯，才把九龙杯讨回来。

所以「救驾」本身很短，真正推动后续剧情的其实是黄马褂+夸海口这个设定。
