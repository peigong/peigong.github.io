# 达氏鹿、大卫神甫鹿和戴维

达氏鹿、大卫神甫鹿和戴维，这三个名字其实不是“三种不同的鹿”，而是同一种动物 + 它的西方命名来源：

## 达氏鹿 = 现生麋鹿的种名简称

现生麋鹿的学名是 Elaphurus davidianus，其中种加词 davidianus 就是“戴维的”意思。

麋鹿属历史上有过几个化石种（蓝田种、晋南种、双叉种等），现存活下来的只有达氏种（E. davidianus），所以“达氏鹿”一般是“达氏麋鹿”的简称，指的就是今天说的麋鹿（四不像）。

## 大卫神甫鹿 / 戴维神甫鹿 = 同一物种的洋名译法

“大卫神甫鹿”“戴维神父鹿”“戴维鹿”都是英文 Père David's deer 的不同中文翻译，指的也是麋鹿。

大卫视 / 戴维 = 译名差异，同源都是法国人 Armand David

神甫 / 神父 = Père（神父）的译法不同

所以“达氏鹿”和“大卫神甫鹿”不是并列的两种鹿，而是同一物种在中文俗名和西文纪念名上的两种叫法。

## 戴维是谁：不是鹿，是给它起西名的人

阿芒·戴维（Armand David），中文名谭卫道，法国传教士兼博物学家。

关键经过：

1865 年他在北京南海子皇家猎苑注意到一种俗称“四不像”的鹿；

弄到皮骨标本寄回法国；

巴黎自然博物馆的米尔恩-爱德华鉴定为新属新种，为纪念发现者，定下 davidianus 和 “David's deer”。

注意：中国人很早就认识麋鹿，“科学发现”指的是进入西方分类学体系那一环，不是中国人没见过。

## 一句话串起来

麋鹿 / 四不像 → 中文正名

达氏鹿 → 现生种的简称（达氏种）

大卫神甫鹿 / 戴维鹿 → 西方纪念 Armand David 的叫法

戴维（大卫） → 法国传教士，不是鹿，是种名 davidianus 的来源

关系就是：达氏鹿 = 大卫神甫鹿 = 麋鹿；戴维是给它冠名的人。
