# 清代，乾隆御笔《鹿角记》图卷

> 参考：[清代，乾隆御笔《鹿角记》图卷](https://weibo.com/ttarticle/p/show?id=2309404375042560544460)

​​在南海子麋鹿苑的展室中，有一只特殊的鹿角放在玻璃罩中向游人展示。走近前仔细观看，在麋角主干上刻有密密麻麻的小字。这就是刻有乾隆皇帝御笔《麋角解说》的那只弥足珍贵的麋鹿角。

发现这只麋鹿角的是我国著名的环保社会活动家、环保作家，曾任原国家环保总局特聘环境使者，《大自然》杂志创办者唐锡阳先生。唐先生当时还在自然博物馆工作。有一年，他在整理一批原为清代故宫收藏的形形色色的各种鹿角时，发现了这只与众不同的鹿角。它不像珊瑚般的驯鹿角，也不像手掌似的驼鹿角，又不像树枝般的马鹿角，还不像矛戟般的梅花鹿角，更不像鸡爪似的白唇鹿角。唐先生注意到，这只鹿角，没有一般鹿额前用来角斗的眉叉，而呈多回二叉分岐状，角的主干分前后一样高的两只。唐先生将这只鹿角尖朝下，柄朝上，倒置在平地上，果真屹立不倒。这是我国民间用角来鉴定麋鹿的最简单的方法。也就在这时，唐先生才发现麋角主干的腹面，隐现着一片蝇头汉字。拂拭掉上面的封尘，就露出了嵌涂着石绿的楷书，是一篇题为《麋角解说》的手记，下款署的是：“乾隆三十二年岁在丁亥仲冬日上浣御制”。

乾隆三十二年(1767)的冬天，天气已经很冷。乾隆皇帝结束了塞外木兰围场的巡狩围猎，返驾回到北京皇宫。刚过冬至开始数九，御花园已是冰封雪盖，天寒地冻。乾隆穿上御寒长袍，披上獭领裘皮斗篷，在御花园的甬路上踏雪散步，脚下发出扑哧扑哧的响声。乾隆喜欢这种有节奏的声响，认为这样有利于思考问题。在康熙、雍正、乾隆三位清代帝王中，后人曾对他们作过这样的评价：康熙善管理、雍正善革新、乾隆善学习。这不无道理。乾隆一生博览群书、勤于思考，是个求知欲甚强的皇帝。他读书善解，从不死背硬记。他曾说，死读书，读死书，读书读死不如不读书，并善于在读书的过程中发现问题。比如当他看到《养吉斋丛录》中称“南苑亦称南海子，在京师二十里”时，感觉不对，就差人进行了实际丈量，结果得出：永定门距南海子北红门为十二里，即在《御制入北红门小猎即事诗》中作了勘正：“出城十里到红门”。又如，乾隆发现明代书籍中均称南海子围墙为“一百六十里”，他又表示怀疑。即派人进行实际丈量，结果海子围墙实际长度为“一万九千二百九十二丈九尺”，折合约一百二十里。立即给予纠正。再有就是乾隆对《日下旧闻考》中所称南海子“水泉七十二处”之说表示质疑，就又派专人进行详细勘查，结果又得出了不同的结论：“则团河之泉指数者九十有四，一亩泉亦也有二十三泉，较旧数殆赢其半，稗野无微大率类是。”也就是说，南海子水泉当时共有一百一十七处，几乎多出一倍。这些都表明，乾隆皇帝对读书、求知、求真是多么严谨。

乾隆在御花园继续边踏雪边思考着，他突然想起在南海子鹿圈放养的被称为“麈”的麋鹿会不会就是仲冬月解角呢？想到这儿，他立即传御前侍卫王福，让他速骑马至南海子鹿圈，看看那里放养的麋鹿是不是在解角。不久，王福从南海子回来了，手里还拿着一只刚刚脱落的麋鹿角，向乾隆禀报道：“回皇上，南海子那里的麋鹿正在解角，有的麋鹿两只角都掉了，有的还刚脱落一只，正歪着头乱蹦呢。”说完，把捡回的一只麋鹿角双手奉上。乾隆接过麋鹿角，看罢“乃爽然自失”，不禁感叹道：“唉，世人把麈当麋，而朕呢？则更错误，竟然不知道还有冬天解角的鹿，事物就是这样不容易摸透啊！”。于是立即铺纸挥毫，写了这篇《麋角解说》，以纠正自己的过错。文中写道：“壬午为鹿角记，既辨明鹿与麋皆解角于夏不于冬。然月令既有其言而未究其故，常耿耿焉。昨过冬至，陡忆南苑有谓麈者或解角于冬，亦未可知。遣人视之，则正值其候，有已　　落地者，有尚在脑骨或双落其一者，持其已解者以归。乃爽然自失曰：‘天下之理不易穷，而物不易格，有如是乎？使不悉麈之解角于冬，将谓月令遂误而不知吾之误，更有甚月令者矣……”

乾隆写完《麋角解说》一文，便命人将此文镌刻在刚检回的那只麋鹿角上，才有了我们今天在南海子麋鹿苑展览室所见到的这只弥足珍贵的麋鹿角。

冬季脱角是麋鹿的一种独特现象。早已引起古人的注意和联想，他们用阴阳二气进行解释，如《尔雅翼》载：“……麋是阴兽，情淫而游泽，冬至得阳气而解角，从阴退象。”这种描述虽有些玄奥，但确含有深刻的道理。古人知道夏至节气后，昼短夜长的日子开始，意味着日温逐渐减少，古称“阳退”之象。冬至节气后，又开始了昼长夜短的日子，意味着日温逐渐增加，故称“阴退”之象。而麋鹿恰好在冬至节气解角，成了象征这个时令转折点的指示动物。

麋鹿是中国特有的鹿种，由于它角似鹿非鹿、头似马非马、蹄似牛非牛、尾似驴非驴，故被民间俗称为“四不像”。世界上鹿的种类众多，麋鹿古代也称麈，常被世人与驼鹿、驯鹿、马鹿相混淆。这一点，就连自称鹿之乡的“北人”乾隆也未完全搞清楚，幸好他知错即改，有自知之明，才未乱下御旨。这虽是一件小事儿，但足以证明乾隆皇帝确实是一位治学严谨的君王。
