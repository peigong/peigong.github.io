# 南海子的动物

## 鸿雁

- 嘴部为黑色，体色浅灰褐色，头顶到后颈为暗棕褐色，前颈近白色。

## 孔雀

- 孔雀被誉为“百鸟之王”，象征着善良、美丽与高贵，是吉祥的象征。
- 孔雀属隶属于雉科，包含蓝孔雀（Pavo cristatus）和绿孔雀（Pavo muticus）两种。
- 绿孔雀分布于中国云南、西藏地区，以及孟加拉、缅甸、中南半岛和印度尼西亚爪哇岛等地。
- 蓝孔雀则分布于印度和斯里兰卡，南海子麋鹿苑的孔雀都是蓝孔雀。
- 绿孔雀是中国野生雉类体形最大的种类，具有显著的雌雄异形异色特征。
- 雄鸟拥有长达其身体两倍的尾屏，尾屏上分布着具有金属光泽的五彩斑纹，部分尾羽末端的眼状斑点中心呈现紫色肾形或圆形。
- 雄孔雀最为显著的特征是其华丽的尾屏，由100-150根延长尾羽构成，展开时可达身长的2倍，上面布满五色金翠钱纹，绚丽夺目。
- 雌鸟无尾屏，背羽主要为浓褐色，略带灰绿色。
- 一般情况下，一只雄孔雀会与3-5只雌孔雀组成群体活动，雄鸟在前领路，雏鸟居中，雌鸟殿后。
- 灵猫是孔雀的主要天敌，云豹偶尔也会捕食孔雀。

## 绿头鸭

- 别名大绿头、官鸭等，是全球家鸭的野生祖先，1758年由林奈命名。
- 雄鸟头颈带亮绿色金属光泽，颈基有白色领环，胸为浓栗色，嘴黄绿、脚红。
- 雌鸟通体褐色布暗褐斑纹，嘴黑褐、脚橙黄。
- 两性翅膀均带标志性金属紫蓝色翼镜。
- 绿头鸭在睡眠中可睁一只眼闭一只眼，这是科学家所发现的动物可对睡眠状态进行控制的首例证据。

## 翼镜

- 翼镜（英文:speculum,意为“反射镜”），也称翅斑，是生物学术语，指鸟类翼上特别明显的块状斑。大多数种类的次级飞羽色彩艳丽，具有金属光泽，被称作翼镜。
- 翼镜与邻近部分的羽毛颜色形成较大反差，呈现色彩艳丽的闪亮光斑，因其像镜子一样亮闪闪的，故而称为“翼镜”。在飞行时很显眼，游泳和在地面站立时则隐约可见。
- 翼镜常见于雁鸭类等鸟类。在野外观察时，闪亮的翼镜有助于快速分辨鸟的种类，是鸟类鉴别的重要辅助手段。
- 闪亮的金属光泽色彩源于羽毛的微观结构对光线的干扰效应（结构色），类似肥皂泡薄膜产生的彩色光辉。
