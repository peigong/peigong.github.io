## 苏州石刻天文图

- 由南宋的黄裳绘制的。
- 绍熙元年(公元1190年)向宋太子赵扩献八图﹐称为“绍熙八图”。
- 世界上现存最古老的根据实测绘制的全天石刻星图。
- 观测年代在北宋元丰年间（1078至1085），刻制年代在南宋1247年。

## 文物遗存

### 赤道经纬仪

- 测定真太阳时，天体的赤经差和赤纬

### 纪限仪（六分仪）

- 测定60度以内任意两颗天体的角距离和日、月的角直径

### 地平经仪

- 测量天体的方位角

### 象限仪（地平纬仪）

- 测量天体的地平高度或天顶距

### 地平经纬仪

- 测定天体的方位角和地平高度
- 康熙五十二年（1713年），纪理安，欧洲文艺复兴法国风格
- 地平经仪和象限仪的功能合二为一
- 熔元代郭守敬简仪

### 黄道经纬仪

- 测量天体的黄经差、黄纬和24节气

### 天体仪

- 测量天体出没的时间和方位，以及求任何时刻天体的地平高度和方位角

### 玑衡抚辰仪

- 测定真太阳时
- 测定真太阳时，天体的赤经差和赤纬
