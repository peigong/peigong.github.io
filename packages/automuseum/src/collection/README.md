# 藏品精选    

北京汽车博物馆始终坚持以“汽车”为载体，以“科学、技术和社会”为核心，超越品牌、区域和国界的差别，讲述汽车工业百年发展历程所带来的科技文明进步、产业迅猛发展、技术不断变革、产品日趋多元的背后故事，揭示车性化、人性化。其中，藏品是博物馆的重要展览元素，我们为此精心开展了藏品的征集遴选工作，并根据“短期满足开馆必须品，中长期不断丰富和完善馆藏”的战略有序推进。藏品征集按照展览陈设大纲，以历史、技术、未来为主线，并且将征集遴选的视野扩大到了除车辆类以外的构成类、文献类、模型类、票牌类、杂项类共6大类，21小类。截止2010年底，汽车博物馆已累积拥有包括80余辆藏品车等在内的各类馆藏品6000余件。

藏品车是博物馆藏品的重要部分，主要包括汽车发展历程中的经典车型和在汽车社会进程中有着重要影响的车辆，虽受条件所限我们的馆藏尚不能全面覆盖汽车发展历史的各个时期和各个车型，但是这些藏品却试图将世界汽车工业的发展脉络和汽车社会多元化发展的规律演绎出来：从古代马车、老式蒸汽机车、单缸摩托车在历史舞台上的演变，直至世界公认的第一辆汽车奔驰一号的出现改变了人类的出行方式，到福特T行车为世界装上了车轮，再到汽车社会的全景图，再到新能源新动力汽车和概念车，世界汽车工业的发展经历了从动力革命到“改变世界的机器”到技术发展和车型多元化再到产业格局的变化发展，通过藏品车都被一一清晰呈现。

还有那些汽车车标，设计巧妙、制作精良以及所传达的品牌价值和精神，无疑是独立于汽车之外的一种收藏；那些老旧得已经发黄的新华社原版照片，定格了中国汽车工业的每一个重要历史瞬间；那些已经残破却依然伫立在橱窗里的书籍和图书杂志，安静而又生动，把人们拉回曾经的那个年代。

通过藏品征集还对中国汽车工业的文化遗存进行了一次抢救性的保护，全面反映了中国汽车社会的历史以及中国汽车工业的发展历程，收藏品涵盖国内外，包括红旗系列、上海系列、北京系列、吉斯吉姆系列、伏尔加系列以及大量文献资料等，具有一定的广泛性和系列性。

## 指南车

指南车是中国古代用来指示方向的一种机械装置。与利用地磁效应而闻名天下的指南针不同，指南车利用了差速齿轮原理，根据车轮的转动，由车上木人指示方向。不论车子转向何方，木人的手始终指向南方。世界著名科技史学家、汉学家李约瑟赞它为“世界上第一个自适应系统”。

关于指南车构造和原理的最早记录见于《宋史•舆服志》。

## 记里鼓车

记里鼓车发明于西汉初年，是中国古代用于计算道路里程的车辆，又称“司里车”、“大章车”。车上有两个木人，车行一里就击一次鼓。记里鼓车和指南车都是皇帝出行时的仪仗车，经常被排列在相同位置。记里鼓车是近代里程表、减速器的先驱，是科学技术史上的一项重大成就。

## 奔驰1号

世界上第一辆以汽油为动力的车开始只有三个轮子，这就是德国人卡尔•本茨（Karl Benz, 1844～1929）于1885年制造出的“奔驰一号”。1886年1月29日，这辆具备了现代汽车特点的车申请了专利，这一天被视为世界汽车的诞生日。这辆车有三个实心的橡胶轮胎车轮，前面一个小轮，后面两个大轮；在两个后轮之间有一台单缸汽油发动机，产生的动力靠齿轮和链条传给装有差速器的后轴，行驶方向靠操纵杆控制。在车架和车轴间还有钢板弹簧悬架，可提高乘坐的舒适感。

“奔驰一号”现藏于德国斯图加特奔驰汽车博物馆，这里展示的是2003年经奔驰公司授权的复制品。

## 杜瑞亚L型（美国）

杜瑞亚汽车公司是美国创建最早的汽车公司之一，其设计生产的杜里埃L型汽车于也是最早进入中国的汽车之一。该车型于1893年开始生产，由于使用手工生产的方式所以产量非常有限，在1903年仅生产了47辆。这里展示的这辆杜瑞亚L型汽车为1903年产的原装汽车，与在颐和园内保着的那辆由袁世凯进贡给慈禧太后的车系出同门，但不同的是，后者经过了加装顶棚等改装。这辆车在1962年修复后被美国汽车协会(AACA)授予First Junior奖，2006年获得Senior奖，目前仍能行驶。

## 红旗CA72轿车（中国）

红旗牌轿车的历史始于1958年，当年5月12日诞生于一汽的我国第一辆国产小轿车被命名为“东风”，生产编号为CA-71，但其并没有真正投入生产。以此样车为基础，1958年8月，一汽第一台高级轿车试制成功并被命名为“红旗”。1958年8月至1959年5月，经多次试验后，红旗轿车定型样车被正式编号为CA72，这是我国有编号的第一辆真正的高级轿车，是我国汽车工业的标志和里程碑。1960年，红旗CA72轿车亮相莱比锡国际博览会，受到了一致好评，并被编入《世界汽车年鉴》。自1959年9月投产下线至1966年停产，红旗CA72轿车陆续生产了202辆。这里展示的这辆车曾为前国家副主席王震用车。

## 吉斯110轿车（前苏联）

基于美国派克公司转让的超8系列180型轿车车身，斯大林汽车厂制造出吉斯110型高级轿车。该车配备6.0升 8缸140匹马力发动机，车速135公里/小时。吉斯110轿车在前苏联为国家元首用车，数量极为稀少，自1945年6月问世到1959年停产，14年中仅生产了2083辆。新中国成立后，斯大林曾赠送给毛泽东主席二辆吉斯汽车。此后又有十多辆陆续进入中国，其中包括五辆吉斯115型防弹轿车。这里展示的这辆车曾为前国家主席刘少奇用车。
