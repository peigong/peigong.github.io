# 老照片背后的故事——清华大学微型汽车的研制历程

在北京汽车博物馆的馆藏文献中，有这样一张拍摄于1959年国庆节当天的老照片，记录了清华大学的学生们驾驶着自制的微型小汽车欢快地走向天安门广场庆祝建国10周年的情景。照片中的微型汽车是我国为了开发自主汽车产品，由清华大学汽车工程系的师生们以理论联系实际，将学习与独创相结合进行尝试研制而成的。1958年首次研制成功，而后又反复测试进行了一些改进，最终实现了小批量生产。那么这张照片背后的故事是怎样的呢？让我们沿着历史的脉络回顾那段“思想火花碰撞，研制激情燃烧”的岁月。

1958年初，我国第二个五年计划正式开始实施，计划中提出“相应发展运输业和商业，提高人民生活水平”的建议。从当时的运输业发展来看，1956年解放牌CA10载货汽车的下线实现了我国汽车工业零的突破，但我国小型汽车的研制仍属空白，市内小型汽车基本以苏联吉斯、吉姆、华沙胜利20等进口车为主，使用也仅限于局级以上的干部。北京市内交通基本依靠人力客运，在街头接送客人的都是人力三轮车。为了改变这种落后面貌，提高人民生活水平，周恩来总理提出了制造微型车的想法。清华大学汽车工程系的师生开始着手研究设计一种结构简单、操作方便、美观大方的微型汽车，并与北京市汽车修配厂合作加工试制。

第一辆微型汽车是清华大学汽车工程系的毕业设计课题。由清华大学余志生、徐大宏、黄实和蔡景泉等几位老师带领着学生们在汽车实验室内进行设计研制，并于1958年7月25日试制成功。这辆微型汽车采用北京摩托车厂生产的单缸发动机，利用自行车车架钢管焊接了一个车架，制成一台前轮驱动、后轮转向的三轮微型汽车。在清华大学校园内试车，引起了校园内师生的围观。

1958年8月，这辆微型汽车参加了清华大学毕业设计成果展。 8月24日，周恩来同志参观展览时看到了这辆小车，给予了很高的评价，并希望清华大学在国庆节之前再设计制造一台更好、更先进的微型汽车向国庆献礼。
 
清华大学汽车工程系的师生们立即投入设计试制工作，这次，他们采用了北京汽车厂制造的四缸风冷发动机的配件，设计了一台单缸发动机；又采用后横置发动机的总布置，避免了汽修厂不能制造的锥齿轮；选用皮带无级传动系统，取消了一般汽车所需的排挡，以便不会开车的三轮车工人驾驶。经过约40个昼夜的努力，终于在1958年国庆节前制成了一台新的微型汽车。
 
1958年国庆期间，这辆微型汽车开进了中南海总理办公室大院。周恩来同志在技术人员的指导下试开了微型汽车，并鼓励大家将车子的噪声和振动再减少一些，将来还可以供家庭使用。

回校后，清华大学的师生们改进了设计，将单缸机改成了卧式对置双缸风冷发动机以减少振动，完成了三轮样车的试制。在此期间，周恩来同志多次带领外国元首来清华大学参观，并向外宾展示微型汽车。

1959年国庆10周年前夕，清华大学汽车工程系的师生们精心打造了三辆定型为V型的微型汽车，参加了国庆游行活动，并拍摄国庆10周年献礼片，开篇那张正是记录了这一珍贵时刻的老照片。国庆之后，这辆微型汽车曾小批量生产了100多辆，组成了出租车队，在北京站和儿童医院运营，直至1961年底。
 
清华大学汽车工程系试制的微型汽车不仅使学生在设计制造的实践中增长了知识和经验，还在一定程度上改变了北京依靠人力客运的面貌，为北京交通运输业的发展做出了贡献。
