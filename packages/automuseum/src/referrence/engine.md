# 深度看展览之动力的变革

在出现能自己行走 动力汽车之前，人力，畜力拉车以及依靠水利、风力驱动的车，持续了几千年。进入18世纪后，蒸汽车的出现为交通运输工具的革命带来了希望。许多发明家、自然学者和机械师投身于蒸汽机作为汽车动力的研究与尝试。随着蒸汽驱动的机械即汽车的诞生，人类踏上了永无止境的汽车创新、发展之途。

汽车的发展史其实就是一部动力变革的进步史，早在公元前3500年前农耕文明社会，人类就已经在劳动实践中获得了启发，开始使用轮子用以运输，而带动轮子的正是人力和畜力这样比较被动的动力。在经历了数千年的漫漫长路之后，始于西方的工业革命打破了这种依靠人力和畜力的格局，17世纪，第一次工业革命在英国的圈地运动中，迅速开展起来，蒸汽动力就是在这样如火如荼的动力革命中诞生了 。1769年，法国炮兵工程师尼古拉斯·古诺大尉经过六年苦心研究，成功地制造出世界上第一辆依靠自身动力行驶的蒸汽动力车，准备用以牵引大炮。古诺的机器是将蒸汽机的动力通过齿轮传到车轮，使车轮变成实际推动车辆运行的工具，这也是今日所有火车、汽车行驶的基本原理。

蒸汽车发明近百年之后，在当时的工业中心英国，人类第一次集中展示了工业革命的伟大结晶，就在这些林林总总的伟大发明背后，发明家们又开始了新一轮的动力研究与探索。1859年，美国宾夕法尼亚州钻出世界上第一口油井，石油作为另一种重要的可利用能源，成为发明家们的新宠儿。新能源的出现，再度掀起新一轮工业革命的浪潮，而这一次，幸运牢牢掌握在了德国人的手中。

1876年，历经十四年的不懈研发，德国人奥托终于制造出由进气、压缩、膨胀、排气四个过程组成的四冲程发动机，其发动原理被称为奥托循环。有了奥托的发明，汽车的诞生才真正成为了可能。

随后，德国人卡尔·本茨在奥托四冲程发动机的基础上，研制出了一种不受轨道限制，能够自由行使的交通工具，这便是依靠汽油发动机为行驶动力的汽车。

无论是古诺在激扬的战火中创造出的历史上第一辆自动之车，还是奥托在挫折与失败的煎熬里研制出的强大动力引擎，还是发明家卡尔·本茨秉承前人的智慧和热忱，实现了人类的汽车梦想。他们都是百年汽车发展史上最卓越的大师，正是他们无止境的热情和动力，推动了改变世界的机器的诞生。

汽车博物馆在五层创造馆诞生发展的这个展区，分别设置了华夏贡献、无马之车、改变世界的机器以及走向大众这四个主题，用细腻多变的展示手法辅以可视、可听、可摸、可参与体验的动态展示手段，突破了“图片+文字+实物”的静态方式，整个展陈按照动力发展的时间脉络，选取了在汽车发展史上最具有节点意义的珍贵展车，例如古代马车、老式蒸汽车、单缸摩托车在历史舞台上的演变，直至世界公认的第一辆汽车奔驰一号的出现改变了人类的出行方式，到福特T型车为世界装上了车轮，再到汽车社会的全景图，再到新能源新动力汽车和概念车，世界汽车工业的发展经历从动力革命到“改变世界的机器”到技术发展和车型多元化再到产业格局的变化发展，通过藏品车都被一一清晰呈现。
