## 汽车生活  Auto Life

有人仅将汽车当做一种空间位移的工具，有人把汽车作为家的延伸，还有人将汽车视为家庭成员。汽车这种由诸多零部件结合而成的高价值耐用消费品，已经成为彰显品味和生活态度的动态载体，成为“第三生活空间”，被不同的人赋予不同的生命力。

汽车生活方式带有社会和个人烙印。品味主义、尊贵主义、先锋主义、完美主义、进取主义、实用主义、激情主义、驾驭主义、商务主义和浪漫主义都是不同的汽车生活方式，代表着拥有不同生活态度的人群。

汽车生活展区设有“汽车魅力”、“电影中的汽车”、“个性化汽车”三个主题。从汽车广告、汽车音乐、汽车电影和个性汽车等多方面诠释了汽车对我们生活的影响和改变。

### 汽车魅力

汽车，使人类超越自身体能实现了自由移动的梦想；汽车，为人类文明发展装上了一日千里的轮子。它的点滴进步都给人类生活带来品质和体验的改变；它引发的现象渗透到生活的每个角落。

汽车广告，调动了人们的购买欲望，激发了人们对未来的无限期待；汽车海报、书刊、展会传递了海量信息；汽车音乐，增添了生活的激情与浪漫。

通信技术、智能技术等现代高新科技更是打破了人们对汽车的原有认知，赋予人们无限的想象和创造空间。汽车已不仅仅是一个代步工具，它还是一个娱乐终端，一个信息中心，一个多功能的私人移动空间。未来它还会给我们带来怎样的惊喜？让我们共同期待吧。

### 电影中的汽车

汽车是电影中的名角，世界电影史上许多经典场面都离不开汽车。汽车成为很多著名电影的卖点，电影也提升了汽车品牌。蝙蝠车随着《蝙蝠侠》系列电影不断升级，《蝙蝠侠6》的海报就是蝙蝠车单轮冲天的神武形象；《007》系列等侦探或探险影片中，那些经特殊装备的汽车，与主人公一起出生入死、创造传奇；《疯狂TAXI》的热映使标致车销量猛增！在这里，多媒体和机械传动装置将为你模拟电影场景的真实气氛，快来尽情感受吧！

### 个性化汽车

伴随着汽车需求的高速增长，城市道路上流动的汽车越来越多。个性化汽车需求让汽车不再是代步工具，人们希望通过自己的双手去改变爱车的外衣、内饰，动力，以期获得更为舒适、个性的驾乘感受。

大众甲壳虫以“卡通可爱、小巧玲珑、与众不同以及不经意间无处不在”的形象深入人心；舒适实用的房车满足着人们户外活动中的衣食住行。在世界很多国家，改装是汽车个性文化的重要组成部分。那些改装后的房车、跑车特立独行，成为都市中炫目的风景。当然，如果一时无法大动干戈地改装你的爱车，也可以在车贴和饰品上动动脑筋，让爱车与众不同。

## 资源环境 Resource & Environment

与汽车文明相伴而生的是能源消耗、空气污染、交通拥堵、安全事故。有人预测，地球上的石油仅能用50年。长期以来，消耗石油的汽车一直在主动寻求改变；替代燃料、混合动力、电动车、氢动力，都有可能成为未来汽车的动力。排放二氧化碳和硫化物，使气候变暖、引发呼吸道疾病，汽车产业应承担起降低排放的责任。重金属、有机化合物、塑料等数百种材料制造的汽车，要积极寻求报废后循环再利用的渠道。交通拥堵吞噬时间，交通事故吞噬生命，寻求改变既依靠智能交通技术的发展，也依靠驾驶者良好的行车习惯。

资源环境展区设有“能源消耗”、“污染排放”、“车辆报废”、“交通拥堵”、“安全事故”五个主题，展示汽车对人类生活及环境的负面影响，引发人们探索人与车、社会、自然和谐发展的途径。

### 汽车回收再利用	

汽车超高的产量和消费量，使报废汽车与日俱增，挤占着人类的生存空间。其实，汽车上的钢铁、有色材料类零部件90％以上可以回收利用，玻璃、塑料等回收利用率也可达50％以上；经处理后，这些零部件仍有很高的使用价值。目前，德国汽车回收率已接近100％；法国、美国等国家报废汽车的再利用率也已达到95％，日本汽车报废回收业分工细致，职责明晰。随着对环保认识的不断深入，我国的汽车回收再利用问题也提上了日程。

关注汽车的回收再利用，通过技术和制度创新、产业转型、新能源开发等多种手段，发展低碳经济，达到经济社会发展与生态环境保护双赢的经济发展形态，是我们的必由之路。
